🧩 Hipótesis de causa raíz

Posibles causas para las secciones con degradación >15%.

🔴 Alta — Comparar
Cambios recientes en la lógica de comparación de especies o en la integración con fuentes de datos externas que ralentizan la recuperación de información.
Problemas de optimización en la renderización de tablas o gráficos complejos al comparar múltiples activos financieros. Un aumento en el volumen o complejidad de los datos de las especies AL30 y TX28 que la UI no maneja eficientemente.
🟡 Media — Mis portafolios
Consultas a la base de datos ineficientes o aumento en la cantidad de datos a procesar para la gestión de portfolios.
Problemas de carga perezosa (lazy loading) o renderizado de componentes al agregar o manipular especies en un portafolio. Un incremento en la complejidad de los cálculos de rendimiento o valorización que se realizan al interactuar con los portafolios.
🔵 Baja — Analizar
La carga inicial del Home ahora incluye más widgets o datos complejos que no se cargan de forma asíncrona.
Problemas de autenticación o autorización que añaden latencia al flujo de ingreso. Un cuello de botella en la API que alimenta los datos iniciales del Home.
