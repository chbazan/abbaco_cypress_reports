Descripción detallada

El test 'Análisis de Sensibilidad de la especie RESA15' falló al esperar que los elementos 'span.placeholder-glow' desaparecieran del DOM. Aunque el screenshot muestra una tabla con datos, el HAR registra un error 405 (Method Not Allowed) en el endpoint de inversiones con parámetros de escenarios y múltiples errores 503 en el servicio de suscripción del usuario. La duración total de 99072ms confirma que Cypress agotó el defaultCommandTimeout de 90s intentando validar la carga completa de la UI.

Posibles causas

ALTA
Error 405 en API de Inversiones
El endpoint 'GET https://api.brasil.mercap.com.ar/investments?scenarios=4&step=4' devolvió 405 Method Not Allowed, lo cual es crítico para el módulo de sensibilidad que depende de escenarios.
ALTA
Error 503 en API de Suscripción
La falla recurrente (503) al obtener el perfil y suscripción del usuario impide que la aplicación resuelva estados de carga globales o permisos de visualización.
MEDIA
Inestabilidad de servicios externos (Staging en Prod)
Se observa un spam masivo de errores 503 desde 'pd.staging.mercap.com.ar', lo que sugiere una configuración incorrecta del ambiente de producción o saturación de servicios de tracking/encuestas.

Pasos de Troubleshooting

1 Verificar disponibilidad y logs de la API de Brasil (api.brasil.mercap.com.ar) para errores 405 y 503.
2 Reproducir el fallo localmente: TARGET_ENV=production TARGET_CLIENT=brasil SPEC=smoke_analizar npm run test
3 Validar manualmente en el navegador si el módulo de Sensibilidad para RESA15 carga todos los componentes sin placeholders.
4 Ejecutar un curl al endpoint de inversiones con los parámetros del HAR para confirmar si el 405 persiste fuera de la app.
5 Revisar la configuración de variables de entorno para asegurar que no se estén llamando servicios de staging en producción.
