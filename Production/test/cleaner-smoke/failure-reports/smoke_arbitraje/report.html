Descripción detallada

El test falló al intentar interactuar con el selector '#first-security input.form-control' dentro del flujo de carga de especies. La evidencia visual muestra que la aplicación cargó una página de 'preview' o marketing del módulo de Arbitraje con candados en el menú lateral, en lugar de la herramienta operativa. El análisis del HAR revela un error 403 Forbidden en el endpoint de Auth0 (/oauth/token), lo que impidió obtener los permisos necesarios para visualizar la funcionalidad.

Posibles causas

ALTA
Error 403 en Auth0 Token Exchange
El HAR registra un POST a mercap-brasil.us.auth0.com/oauth/token con status 403. Sin un token válido, la app no habilita los módulos premium.
MEDIA
Usuario de test sin suscripción Expert
La UI muestra explícitamente 'Disponível em: Plano Expert'. Si la sesión se inició pero el usuario no tiene el rol adecuado en el ambiente de Brasil, el elemento buscado nunca se renderizará.
BAJA
Expiración de cy.session
Aunque se usa cy.SessionAbbaco(), un error 403 sugiere que el token cacheado fue rechazado por el servidor de identidad.

Pasos de Troubleshooting

1 Verificar manualmente si las credenciales de producción/brasil tienen acceso al módulo de Arbitraje.
2 Ejecutar el test localmente con la interfaz abierta: TARGET_ENV=production TARGET_CLIENT=brasil npx cypress open --config-file cypress.config.js
3 Revisar los logs de Auth0 para el tenant de Brasil buscando el motivo del error 403 (ej: IP bloqueada, cliente deshabilitado).
4 Limpiar el estado de la sesión localmente y re-ejecutar: npm run cy:run -- --spec cypress/e2e/smoke_arbitraje.cy.js --env client=brasil
5 Validar que el secreto de Auth0 para el ambiente de Brasil no haya expirado en el CI/CD.
