Descripción detallada

El test falló durante el flujo de filtrado en el Screener al intentar seleccionar una ley. La ejecución se detuvo en el paso 'Selecciona Ley Argentina en Ley' porque el contenido 'Seleccionar Ley' no apareció en el DOM. La captura de pantalla muestra un banner rojo de 'Network Error' indicando un fallo específico al obtener los datos de Ley, lo que resultó en un agotamiento del timeout de 90000ms.

Posibles causas

ALTA
Error 4xx/5xx en endpoint de leyes
La UI muestra explícitamente 'Network Error: Ocurrió un error al obtener Ley'. Aunque el extracto del HAR no muestra el fallo, el mensaje visual confirma que una petición crítica falló o fue bloqueada.
MEDIA
Inconsistencia en la carga de metadatos
El componente Screener depende de múltiples endpoints de Mercap; si el de leyes falla o tarda demasiado, el selector queda inhabilitado o vacío, provocando el timeout de Cypress.

Pasos de Troubleshooting

1 Verificar si el ambiente de producción tiene degradación de servicios en la API de Mercap
2 Reproducir el fallo localmente: TARGET_ENV=production TARGET_CLIENT=argentina MODE=only SPEC=smoke_screener npm run test
3 Abrir la consola del navegador en la captura o video para identificar el endpoint exacto que disparó el 'Network Error'
4 Validar manualmente en la web si el selector de Ley carga opciones correctamente
5 Revisar logs de backend para el endpoint de jurisdicciones/leyes en el timestamp del fallo
