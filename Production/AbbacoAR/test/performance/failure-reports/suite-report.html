Descripción detallada

El test 'Eliminar todas las especies del portafolio' falló al intentar encontrar el elemento con el selector `#select-row-all`. Cypress agotó su `defaultCommandTimeout` de 90 segundos esperando este elemento, lo que indica que no se renderizó en la interfaz. El screenshot y el DOM al momento del fallo muestran la vista general de 'Mis Portafolios' con las tarjetas de los portafolios, pero no una tabla de especies ni un control para 'seleccionar todo'. Los logs de red (HAR) no muestran errores ni latencias en las llamadas a la API, sugiriendo que el problema no es de backend.

Posibles causas

ALTA
El componente de la tabla de especies o el control 'seleccionar todo' no se cargó.
El error 'Expected to find element: `#select-row-all`, but never found it' y la duración de 90537ms (exactamente el timeout) indican que el elemento nunca apareció. El DOM al fallo no contiene este selector, y el screenshot muestra la página de portafolios sin una tabla de detalle visible.
MEDIA
Un paso previo en el flujo de eliminación de especies no se completó correctamente.
El fallo ocurre en las funciones `deleteIcon` y `deleteEspecies` de `portafolioPage.js`, lo que sugiere que el test estaba en el proceso de eliminar elementos. Si la navegación o la carga de la vista de detalle de un portafolio falló, el selector `#select-row-all` no estaría presente.
BAJA
Cambio en el selector del elemento 'seleccionar todo'.
Aunque el selector `#select-row-all` no se encuentra en el DOM al fallo, no hay evidencia de un elemento similar con un ID o clase diferente que cumpla la misma función. El DOM baseline es similar, lo que no ayuda a identificar un cambio reciente.

Pasos de Troubleshooting

1 Reproducir el spec fallido localmente: `TARGET_ENV=production TARGET_CLIENT=argentina MODE=only SPEC=performance/portafolio.js npm run test`
2 Abrir la aplicación manualmente en producción y navegar a 'Mis Portafolios', luego intentar acceder a la gestión de especies de un portafolio para verificar si el control 'seleccionar todo' aparece.
3 Revisar los logs de la aplicación en Datadog para buscar errores de frontend o warnings relacionados con la carga de componentes en la vista de portafolios.
4 Inspeccionar el código fuente del componente de la tabla de especies para verificar si el selector `#select-row-all` sigue siendo válido o si ha sido modificado.
