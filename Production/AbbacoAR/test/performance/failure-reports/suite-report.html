Descripción detallada

El test ejecutaba el flujo de ingreso a una curva específica dentro del módulo de Curvas Argentina. Tras aplicar el filtro 'Todas', Cypress intentó localizar un elemento 'a' que contuviera el texto exacto 'Corporativos - ONs TAMAR - ARS'. El fallo ocurrió por agotamiento del timeout de 90s (90613ms totales), ya que el elemento nunca apareció en el DOM. La captura de pantalla y el DOM-FALLO muestran que existen otras curvas similares (ej: 'Corporativos - Bancos Comerciales - Tasa TAMAR'), pero no la buscada.

Posibles causas

ALTA
Curva inexistente o renombrada
El DOM-FALLO contiene 32 ítems en la lista de curvas, incluyendo 'Corporativos - Bancos Comerciales - Tasa TAMAR', pero el string exacto 'Corporativos - ONs TAMAR - ARS' no existe. Es altamente probable que el nombre de la curva haya cambiado en el backend.
BAJA
Filtro de UI no procesado
Aunque el test hizo click en 'Todas', si la lista es dinámica y hubo un retraso en la actualización del estado de React, el elemento podría haber tardado en renderizarse, pero 90s es tiempo suficiente para descartar un simple lag de UI.

Pasos de Troubleshooting

1 Verificar manualmente en https://bonds.mercapabbaco.com/curves si la curva 'Corporativos - ONs TAMAR - ARS' aparece al filtrar por 'Todas'.
2 Reproducir el fallo localmente: TARGET_ENV=production TARGET_CLIENT=argentina SPEC=performance/curvas.js npm run test
3 Inspeccionar el HAR para buscar la respuesta de la API de curvas y confirmar si el objeto con ese nombre exacto viene en el JSON de respuesta.
4 Consultar con el equipo de datos si hubo cambios en la nomenclatura de las curvas corporativas recientemente.
