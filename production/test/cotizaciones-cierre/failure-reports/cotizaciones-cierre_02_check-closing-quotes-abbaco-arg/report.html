Descripción detallada

El test falló durante la ejecución de 'Validar en Abbaco que el bono AL30 tenga volúmen según la fecha de su último precio de cierre'. La aserción personalizada en commands.js (línea 173) agotó el timeout de 90s buscando un elemento de Highcharts (path o rect) cuyo aria-label coincida con la fecha de cierre. Aunque la captura de pantalla muestra el gráfico renderizado con datos, el test no logra localizar la vela específica, lo que indica un mismatch entre la fecha buscada y los datos presentes en el DOM del gráfico.

Posibles causas

ALTA
Mismatch de fecha en el gráfico
El gráfico de Highcharts podría no tener aún cargada la vela correspondiente a la última fecha de cierre que el test detectó como válida, provocando que el loop de búsqueda falle por timeout.
MEDIA
Cambio en estructura de Highcharts
Una actualización en la librería de gráficos o en la configuración de accesibilidad podría haber alterado el formato del 'aria-label', haciendo que el selector 'g.highcharts-series path[aria-label]' no encuentre el match de texto esperado.
BAJA
Carga incompleta de datos históricos
La API de series históricas podría haber devuelto un set de datos parcial que no incluye el último día, a pesar de que la UI del encabezado muestra una cotización de cierre reciente.

Pasos de Troubleshooting

1 Reproducir el fallo localmente: TARGET_ENV=production TARGET_CLIENT=argentina SPEC=cotizaciones-cierre_02_check-closing-quotes-abbaco-arg npm run test
2 Inspeccionar manualmente el DOM del gráfico en producción para verificar el contenido exacto del atributo 'aria-label' en las velas.
3 Verificar si la fecha que el test intenta buscar (visible en logs de Cypress previos al fallo) existe efectivamente como una vela en el gráfico.
4 Revisar en el HAR si la request a la API de series históricas para AL30 devolvió el punto de datos correspondiente a la fecha de cierre.
5 Ejecutar el test en modo encabezado (headed) para observar el tooltip del gráfico durante la ejecución.
