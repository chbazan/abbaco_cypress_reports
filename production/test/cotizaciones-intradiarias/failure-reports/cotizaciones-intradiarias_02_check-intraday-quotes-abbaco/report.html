Descripción detallada

El test ejecutaba la validación de precios intradiarios para el bono AL30 en el módulo Analizar. El fallo ocurrió en la aserción final donde el valor extraído del DOM (90570.009) se comparó contra la referencia de Pepper (90590). La diferencia de ~20 unidades indica una desincronización de datos de mercado, ya que la captura de pantalla muestra '90.570,00' en la UI, confirmando que el valor en Abbaco está desactualizado respecto a la expectativa del test.

Posibles causas

ALTA
Delay en la ingesta de datos de mercado
La API de Mercap (historical-data.mercapabbaco.com) respondió correctamente (200 OK), pero el valor servido a la UI no alcanzó el precio de referencia de Pepper a tiempo para la aserción.
MEDIA
Error de precisión en la extracción del DOM
El log muestra un valor extraído de '90570.009' mientras la UI muestra '90.570,00'. Esta discrepancia de decimales sugiere que el selector span.me-2 podría estar capturando datos crudos del componente que no coinciden con el redondeo esperado.
BAJA
Volatilidad extrema del activo
Un movimiento brusco de precio en el bono AL30 durante la ejecución del test pudo haber dejado obsoleta la referencia de Pepper antes de que Abbaco actualizara el componente.
