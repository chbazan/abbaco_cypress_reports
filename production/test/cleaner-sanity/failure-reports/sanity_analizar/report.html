Descripción detallada

El test 'Ingresar al home' falló al intentar localizar el elemento 'Índices' dentro de un selector de encabezado tras agotar el timeout de 90s. La captura de pantalla revela que la aplicación se encuentra en estado 'invitado' (botones 'Iniciar Sesión' visibles y candados en el menú lateral), lo que impide la carga del dashboard privado. El HAR confirma múltiples errores 401 Unauthorized en endpoints de anuncios y una respuesta extremadamente lenta de Auth0 (21s) durante el flujo de autorización.

Posibles causas

ALTA
Sesión de Auth0 inválida o expirada
El HAR muestra ráfagas de errores 401 en api.mercapabbaco.com y la UI muestra elementos de navegación bloqueados, confirmando que el token no fue inyectado o es inválido.
MEDIA
Timeout en el handshake de autenticación
El endpoint /authorize de auth.mercapabbaco.com tardó 21016ms, lo que pudo causar que cy.SessionAbbaco() fallara silenciosamente o no llegara a establecer la cookie de sesión a tiempo.
BAJA
Redirección incorrecta post-login
La screenshot muestra la vista de 'Analizar AL30' en lugar del Home, sugiriendo que el flujo de navegación se desvió o no se completó tras el intento de login.

Pasos de Troubleshooting

1 Verificar manualmente si el ambiente de producción permite el login con las credenciales de test: TARGET_ENV=production npm run cy:open
2 Revisar los logs de Auth0 para el ClientID 3M3Hcs5HlUwtxnJ2okb4zZa5Fhh4Eq40 buscando fallos de intercambio de código
3 Ejecutar el spec de forma aislada para descartar contaminación de sesión: MODE=only SPEC=sanity_analizar npm run test
4 Validar si el comando personalizado cy.SessionAbbaco() está manejando correctamente los tiempos de respuesta altos (>20s) de Auth0
5 Inspeccionar el estado de la cookie 'app_session' en el navegador durante la ejecución del test
