Timeout 90s en Sensibilidad RESA15: Error 405 en API de inversiones impide carga de escenario simulado

Descripción detallada

El test falló al intentar validar la aparición del texto 'Cenário simulado' tras ejecutar la acción de análisis. La UI mostró en su lugar un mensaje de error: 'Não foi possível realizar a análise de sensibilidade', el cual no está contemplado en la expresión regular de la aserción. El análisis del tráfico de red revela un error 405 (Method Not Allowed) en el endpoint de inversiones y un 504 (Gateway Timeout) en el servicio de suscripciones, lo que detuvo el flujo de datos.

Posibles causas

ALTA
Error 405 en API Mercap
El HAR registra un status 405 en la petición GET a /investments?scenarios=4&step=4. Esto sugiere un cambio en la API o un error en el método HTTP utilizado por el frontend.
MEDIA
Timeout 504 en servicio de suscripción
La petición a /user-profiles/.../subscription tardó 15s y devolvió 504, lo que podría estar bloqueando la lógica de negocio necesaria para habilitar el análisis.
BAJA
Aserción de test incompleta
El test busca '/Cenário simulado|Error inesperado/i', pero la UI muestra 'Não foi possível realizar a análise...', lo que causa el timeout de 90s al no coincidir los textos.

Pasos de Troubleshooting

1 Verificar disponibilidad de api.brasil.mercap.com.ar y estado de servicios en producción Brasil.
2 Reproducir el fallo localmente: TARGET_ENV=production TARGET_CLIENT=brasil MODE=only SPEC=smoke_analizar npm run test
3 Validar el endpoint /investments con método GET mediante curl o Postman para confirmar el 405.
4 Revisar logs de infraestructura (Datadog/Cloudwatch) para identificar la causa del 504 en el servicio de perfiles de usuario.
5 Actualizar la aserción en ejecutarFlujo (commands.js:1807) para incluir el mensaje de error específico observado en la UI.
