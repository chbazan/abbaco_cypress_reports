Selector #search-security-for-sensitivity no encontrado — Fallo de autenticación Auth0 (403 Invalid Grant).

Descripción detallada

El test falló al no encontrar el buscador de especies en el módulo de Sensibilidad. El HAR muestra un error 403 en el intercambio de tokens de Auth0 con el mensaje 'Invalid authorization code'. El screenshot confirma que la aplicación redirigió al usuario a una página de 'teaser' o venta de planes en lugar de cargar la herramienta, debido a la falta de una sesión válida.

Posibles causas

ALTA
Código de autorización de Auth0 expirado o reutilizado
El error 'invalid_grant' en el POST a /oauth/token es característico de problemas en el handshake de autenticación durante la creación de la sesión.
ALTA
Redirección por falta de permisos (Upsell)
El screenshot muestra el botón 'Ver planos de assinatura', indicando que el usuario fue tratado como invitado o sin suscripción activa.

Pasos de Troubleshooting

1 Verificar logs de Auth0 para el tenant de Brasil buscando errores de intercambio de código.
2 Limpiar caché de sesión local y re-ejecutar: TARGET_ENV=production TARGET_CLIENT=brasil npm run cy:open
3 Validar que las credenciales utilizadas en el test tengan los permisos de 'Plan Experto' necesarios para Sensibilidad.
4 Ejecutar el spec individualmente para descartar problemas de polución de estado entre tests: npm run test -- --spec cypress/e2e/smoke/sensibilidad.cy.js
