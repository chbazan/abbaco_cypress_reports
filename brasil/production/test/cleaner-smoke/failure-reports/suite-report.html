Timeout 90s en botón de favoritos de RESA15 — Errores 401 en API indican sesión no iniciada o expirada

Descripción detallada

El test intentaba guardar la especie RESA15 como favorita en el ambiente de Brasil. Falló al no encontrar el botón con el texto 'Salvar como favorito' tras agotar el timeout de 90 segundos. La captura de pantalla muestra que la aplicación se encuentra en estado de invitado (botones 'Entrar' y 'Criar Conta' visibles, candados en el menú lateral), y el log de comandos de Cypress registra múltiples errores 401 (Unauthorized) hacia la API de Mercap Brasil.

Posibles causas

ALTA
Sesión de Auth0 inválida o expirada
La presencia de errores 401 en el log de Cypress y la visualización de botones de login en la UI confirman que el usuario no está autenticado al momento de intentar la acción.
MEDIA
Fallo en la restauración de cy.session
El comando cy.SessionAbbaco() podría estar recuperando una sesión cacheada que no es válida para el dominio de Brasil (.com.br) o que ya ha expirado en el servidor.
BAJA
Cambio en etiquetas de internacionalización (i18n)
Aunque menos probable dado el error 401, el selector busca un texto específico que podría haber cambiado en la versión de Brasil.

Pasos de Troubleshooting

1 Verificar manualmente el acceso y login en https://bonds.mercapabbaco.com.br/
2 Ejecutar el test localmente con: TARGET_ENV=production TARGET_CLIENT=brasil SPEC=smoke_favoritos npm run cy:open
3 Limpiar el cache de Cypress y cookies locales para forzar una nueva sesión de Auth0
4 Revisar la configuración de cy.SessionAbbaco() para asegurar compatibilidad con el dominio brasilero
5 Verificar en los logs de la API de Mercap el motivo exacto de los errores 401
