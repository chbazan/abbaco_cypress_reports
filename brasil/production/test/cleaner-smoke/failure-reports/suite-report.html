Fallo de sesión Auth0 (403 invalid_grant) impide acceso al módulo de Arbitraje en producción/brasil.

Descripción detallada

El test intentaba ejecutar el flujo de carga de especies en Arbitraje pero falló al no encontrar el selector '#first-security input.form-control' tras 90s. La captura de pantalla muestra una pantalla de bloqueo/upsell ('Aumente seu arsenal...') en lugar de la interfaz operativa. El HAR confirma un error 403 en el intercambio de tokens de Auth0 ('invalid_grant'), lo que indica que la sesión no se estableció correctamente.

Posibles causas

ALTA
Fallo de intercambio de código Auth0 (403)
El HAR muestra un POST a /oauth/token con respuesta 403 'Invalid authorization code'. Esto ocurre cuando el código de autorización de Auth0 es inválido o ya fue utilizado, impidiendo el login exitoso.
MEDIA
Sesión cacheada inválida en Cypress
cy.session pudo haber restaurado una sesión cuyo token ya no es válido para el tenant de Brasil, provocando que la app muestre la pantalla de 'Ver planos de assinatura' por falta de permisos.

Pasos de Troubleshooting

1 Verificar manualmente el login en https://bonds.mercapabbaco.com.br/arbitrage usando el tenant de Brasil.
2 Ejecutar el test localmente forzando la recreación de sesión: TARGET_ENV=production TARGET_CLIENT=brasil npm run cy:open
3 Revisar los logs de Auth0 para el Client ID rGEOIklTSoHWfw7SYVJV29LisYSpcHJt buscando errores de 'invalid_grant'.
4 Validar si las credenciales utilizadas en el CI para el ambiente Brasil han expirado o fueron rotadas.

Error 403 en Auth0 bloquea creación de portafolio; se visualiza pantalla de suscripción en lugar de la herramienta.

Descripción detallada

Durante el flujo de creación de portafolio, Cypress no encontró el botón 'Novo portfólio' dentro del timeout de 90s. La UI en el screenshot muestra un mensaje de 'Aumente seu arsenal de dados', indicando que el usuario no tiene permisos activos. El HAR registra un fallo 403 en el endpoint /oauth/token de Auth0 con el mensaje 'Invalid authorization code'.

Posibles causas

ALTA
Auth0 invalid_grant en producción/brasil
El error 403 en el intercambio de tokens (invalid_grant) es idéntico al del spec anterior, confirmando un problema sistémico de autenticación en este run para el tenant de Brasil.
MEDIA
Fallo de persistencia de cy.session
La sesión cacheada no contiene los claims necesarios o el token de acceso falló al generarse, resultando en la visualización del componente de upsell/bloqueo.

Pasos de Troubleshooting

1 Reproducir el fallo localmente: TARGET_ENV=production TARGET_CLIENT=brasil SPEC=smoke/portafolio npm run test
2 Verificar si el usuario de prueba tiene el plan 'Expert' o 'Avançado' activo en el ambiente de producción Brasil.
3 Inspeccionar el tráfico de red en el navegador para confirmar si el token JWT devuelto por Auth0 contiene los permisos de portafolio.
4 Limpiar cookies y localStorage del navegador y reintentar el flujo manualmente.
