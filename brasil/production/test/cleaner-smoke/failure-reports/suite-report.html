Timeout 90s buscando botón 'Novo portfólio' en producción/brasil debido a fallo 403 en Auth0 (invalid_grant)

Descripción detallada

El test 'Crear un nuevo portafolio' falló al intentar localizar el botón de creación dentro del módulo de portafolio. Aunque la UI llegó a cargar la vista 'Meu Portfólio', el sidebar muestra iconos de candado y la red reporta un error 403 en el endpoint /oauth/token de Auth0. El mensaje de error 'invalid_grant' confirma que el intercambio de credenciales falló, impidiendo que la aplicación renderice los elementos de acción para usuarios autenticados.

Posibles causas

ALTA
Error de Auth0: invalid_grant
El HAR muestra un POST a /oauth/token con status 403 y el body 'Invalid authorization code'. Esto ocurre cuando el código de intercambio expira, se usa dos veces o la sesión de Auth0 no coincide con el estado del cliente.
MEDIA
Sesión cacheada inválida en Cypress
cy.session() podría estar restaurando un estado de sesión que el servidor de Auth0 ya considera expirado, provocando que la app no cargue las funcionalidades completas (visibles candados en el screenshot).
BAJA
Desincronización de tiempo en el runner
Si el reloj del entorno de ejecución está desincronizado con Auth0, los tokens o códigos de autorización pueden ser rechazados inmediatamente por 'expiración'.

Pasos de Troubleshooting

1 Verificar el estado del servicio de Auth0 para la región Brasil.
2 Reproducir localmente forzando login fresco: TARGET_ENV=production TARGET_CLIENT=brasil MODE=only SPEC=smoke_portafolio npm run test
3 Inspeccionar los logs de Auth0 para el client_id rGEOIklTSoHWfw7SYVJV29LisYSpcHJt buscando fallos de 'Exchange'.
4 Verificar si el comando cy.SessionAbbaco() está manejando correctamente la invalidación de sesiones expiradas.
5 Ejecutar el test con el browser visible (headed) para observar si hay redirecciones inesperadas durante el login.
