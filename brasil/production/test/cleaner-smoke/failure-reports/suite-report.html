Timeout 90s buscando botón de favorito en RESA15 — Errores 401 en API Mercap impiden carga de acciones.

Descripción detallada

El test intentaba ejecutar el flujo de 'Guardar como favorita la especie RESA15'. Falló al intentar localizar el botón con el texto 'Salvar como favorito' (o su variante en español) mediante un selector de tipo button. Aunque el HAR no reporta errores, el log de comandos en el screenshot muestra múltiples peticiones GET con estado 401 a api.brasil.mercap.com.ar, lo que indica que la sesión no tiene los permisos necesarios para cargar los componentes de interacción del usuario.

Posibles causas

ALTA
Token de sesión inválido o expirado
El log de Cypress muestra errores 401 constantes al intentar consultar la API de mercado, lo que suele ocurrir cuando el token inyectado por cy.session no es reconocido por el backend de Brasil.
MEDIA
Falta de permisos en el perfil del usuario
Si el usuario de test no tiene habilitada la funcionalidad de favoritos en el ambiente de producción/brasil, la API rechazará las peticiones y el botón no se mostrará.

Pasos de Troubleshooting

1 Verificar manualmente si el usuario de test puede loguearse y ver favoritos en bonds.mercapabbaco.com.br
2 Ejecutar localmente: TARGET_ENV=production TARGET_CLIENT=brasil SPEC=smoke/favoritos.cy.js npm run test
3 Revisar la configuración de cy.SessionAbbaco() para el tenant de Brasil
4 Verificar en el dashboard de Auth0 si hay logs de 'Failed Exchange' para este usuario

Elemento #search-security-for-sensitivity no encontrado — Error 403 en Auth0 (invalid_grant).

Descripción detallada

El test falló al intentar interactuar con el buscador de especies en el módulo de Sensibilidad. El error de Cypress indica que el selector #search-security-for-sensitivity nunca apareció. La evidencia del HAR muestra un fallo crítico en el intercambio de tokens de Auth0 (POST /oauth/token) con un error 403 'invalid_grant', lo que provocó que la aplicación cargara una vista restringida (Plan Experto) en lugar de la herramienta completa.

Posibles causas

ALTA
Fallo en el intercambio de código por token en Auth0
El HAR registra un 403 con el mensaje 'Invalid authorization code', lo que indica que el flujo de login falló antes de que la app pudiera inicializarse correctamente.
MEDIA
Usuario sin suscripción 'Plan Experto'
El screenshot muestra un banner de 'Disponível em: Plan Experto', sugiriendo que el usuario actual no tiene los permisos necesarios para ver el buscador.

Pasos de Troubleshooting

1 Verificar el estado del servicio de Auth0 para el tenant mercap-brasil.us.auth0.com
2 Ejecutar con debug de sesión: DEBUG=cypress:session npm run test -- --spec flows/sensibilidad.js
3 Validar que las credenciales en el archivo de configuración tengan asignado el Plan Experto en producción
4 Verificar si el redirect_uri configurado en el test coincide exactamente con el permitido en Auth0
