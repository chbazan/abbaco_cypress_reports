Timeout 90s: No se encontró el input de edición en la celda TIR de la Calculadora.

Descripción detallada

El test intentaba editar el valor de la TIR en la tabla de simulaciones. Tras localizar la celda (@celdaTIR), Cypress esperó 90 segundos a que apareciera un elemento 'input' para ingresar el dato, pero este nunca se renderizó. La captura de pantalla muestra la tabla cargada pero sin el estado de edición activo en la fila correspondiente.

Posibles causas

ALTA
Falla en el trigger del modo edición
El clic en la celda no activó el componente de edición. Puede deberse a un cambio en el comportamiento del componente de tabla en el ambiente de Brasil.
MEDIA
Cambio de selector en el DOM
El elemento de entrada ya no es un 'input' directo o su jerarquía dentro de la celda cambió, invalidando el comando .find('input').

Pasos de Troubleshooting

1 Reproducir localmente: TARGET_ENV=production TARGET_CLIENT=brasil SPEC=smoke/calculadora npm run test
2 Verificar manualmente en la URL de la calculadora si el clic en la columna TIR habilita la edición.
3 Inspeccionar el DOM con cy.pause() para validar el selector real del campo de edición.
4 Revisar si hay errores de JS en la consola del navegador durante la interacción manual.

Timeout 30s: No se encontró el botón de favoritos en la página de análisis de RESA15.

Descripción detallada

El flujo intentaba guardar la especie RESA15 como favorita. Cypress buscó un botón con el texto 'Salvar como favorito' (o variantes) durante 30s sin éxito. La screenshot revela que la página muestra los botones 'Criar Conta' y 'Entrar', indicando que la sesión de usuario no está activa.

Posibles causas

ALTA
Sesión de Auth0 no persistida
La presencia de 'Criar Conta' en el header confirma que el usuario no está autenticado, impidiendo que el botón de favoritos sea visible.
BAJA
Mismatch de traducción en Brasil
Si la sesión estuviera activa, el texto del botón podría no coincidir con el regex esperado en portugués.

Pasos de Troubleshooting

1 Verificar el estado de la sesión: TARGET_ENV=production TARGET_CLIENT=brasil npm run cy:open
2 Revisar los logs de cy.SessionAbbaco() para confirmar si el token de Auth0 se obtuvo correctamente.
3 Validar manualmente si el botón de favoritos aparece tras un login manual en el ambiente de producción Brasil.

El test falló de forma inmediata (876ms) debido a un error de JavaScript en el código de automatización. Se intentó invocar 'chartElementsLegend' como una función, pero el objeto no la reconoce como tal. Esto ocurre antes de cualquier interacción real con la interfaz del graficador.

Posibles causas

ALTA
Inconsistencia en el Page Object
El elemento 'chartElementsLegend' probablemente está definido como un getter en graficadorPage.js, pero el spec lo invoca con paréntesis ().
MEDIA
Elemento no definido
La propiedad no existe en el objeto 'elements' del Page Object importado.

Pasos de Troubleshooting

1 Abrir cypress/support/pages/graficadorPage.js y verificar la definición de chartElementsLegend.
2 Corregir la llamada en smoke/graficador.js eliminando los paréntesis si es un getter.
3 Ejecutar el test localmente para confirmar que el error de tipo desaparece.
