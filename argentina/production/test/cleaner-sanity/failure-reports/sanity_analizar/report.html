Timeout 90s en placeholder de TX28 al simular inversión — Error 503 en API /investments

Descripción detallada

El test ejecutaba el flujo de simulación de inversión para la especie TX28 en el módulo Analizar. El fallo ocurrió al intentar validar que los elementos de carga (span.placeholder-glow) desaparecieran de la UI, agotando el timeout de 90000ms. La evidencia visual muestra un mensaje de 'Network Error' en la interfaz y el HAR confirma que el endpoint de inversiones falló sistemáticamente.

Posibles causas

ALTA
Indisponibilidad del servicio /investments
El HAR registra dos peticiones POST a https://api.mercapabbaco.com/investments/ con status 503. La UI muestra explícitamente 'Network Error' y mantiene los esqueletos de carga activos.
MEDIA
Timeout de respuesta del backend
Aunque el error fue 503, la duración total del test de 90s indica que Cypress esperó la recuperación del estado de la UI que nunca sucedió por la falta de datos.

Pasos de Troubleshooting

1 Verificar disponibilidad del ambiente de producción y estado de los microservicios de Mercap.
2 Reproducir el fallo localmente ejecutando: TARGET_ENV=production TARGET_CLIENT=argentina MODE=only SPEC=sanity_analizar npm run test
3 Validar el endpoint fallido mediante Postman o curl usando el payload capturado en el HAR para /investments.
4 Revisar logs de errores 5xx en Datadog o Cloudwatch para el servicio api.mercapabbaco.com.
5 Verificar si el error es específico para la especie TX28 o generalizado para cualquier simulación.
