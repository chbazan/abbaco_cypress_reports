Descripción detallada

El test 'Eliminar todas las curvas favoritas' falló al intentar limpiar la lista de favoritos. Cypress ejecutó el comando 'desmarcarSiguiente' y esperó 60s a que el elemento 'svg.tabler-icon-star-filled' desapareciera, pero este permaneció visible. La captura de pantalla muestra múltiples curvas con la estrella amarilla activa, indicando que la acción de desmarcar no se procesó o no actualizó el DOM.

Posibles causas

ALTA
Race condition en el loop de desmarcado
El comando recursivo 'desmarcarSiguiente' puede estar intentando interactuar con un elemento que cambió de estado internamente pero no se removió del DOM a tiempo.
MEDIA
Latencia en Auth0 impactando sesión
El HAR registra un request a auth.mercapabbaco.com de 10.4s, lo que podría haber degradado la performance de las validaciones de permisos posteriores.

Pasos de Troubleshooting

1 Reproducir localmente: TARGET_ENV=production TARGET_CLIENT=argentina MODE=only SPEC=cleaner.cy.js npm run test
2 Verificar en la consola del browser si el click en la estrella dispara el request DELETE a /favorites/yieldCurve.
3 Revisar logs de la API de favoritos para el usuario de test en producción.
4 Aumentar el timeout de la aserción 'not.exist' si la API de favoritos presenta degradación conocida.
