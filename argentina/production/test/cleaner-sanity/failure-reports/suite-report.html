Timeout de 60s en placeholder de BDC28 al simular inversión — los indicadores de carga no desaparecieron de la UI.

Descripción detallada

El flujo ejecutaba la simulación de inversión para el bono BDC28 dentro del módulo 'analizar'. El fallo ocurrió en el paso de validación donde se espera que los elementos de carga (span.placeholder-glow) desaparezcan para interactuar con los resultados. La evidencia muestra que, tras 60 segundos de reintentos, 45 placeholders permanecieron visibles en el DOM, bloqueando la continuación del test.

Posibles causas

ALTA
Latencia crítica en API de métricas
El HAR registra requests lentos a /investments/6435/metrics (12.4s). Aunque terminaron con éxito, la acumulación de latencia o una respuesta incompleta pudo impedir que el componente de React disparara el cambio de estado para ocultar los placeholders.
MEDIA
Race condition en el manejo de estado de la UI
El componente de simulación podría no estar reaccionando correctamente a la llegada de datos asincrónicos bajo condiciones de carga lenta, manteniendo el estado 'loading' de forma indefinida a pesar de tener los datos disponibles.
BAJA
Degradación de performance en ambiente de producción
El tiempo total del test (122s) y la persistencia de placeholders sugieren una respuesta general lenta de la infraestructura que excede los umbrales de espera definidos en el Page Object.

Pasos de Troubleshooting

1 Reproducir el spec fallido localmente: TARGET_ENV=production TARGET_CLIENT=argentina MODE=only SPEC=sanity_analizar npm run test
2 Verificar manualmente la carga de la pestaña 'Simular inversión' para el bono BDC28 en producción para observar si los placeholders desaparecen.
3 Ejecutar 'npm run analyze-failure -- sanity_analizar' para revisar el video y confirmar si algún request quedó 'pending' más allá de lo reportado en el HAR.
4 Verificar en Datadog o logs de backend el tiempo de respuesta del endpoint /metrics para la especie BDC28.
5 Validar si hay errores de JavaScript en la consola del navegador durante la carga de la simulación que puedan interrumpir el renderizado.
