Descripción detallada

El flujo ejecutaba el ingreso a la curva 'Mexico - Soberanos - Bonos Globales - USD' y la validación de su cuadro de bonos. El fallo ocurrió al esperar que los elementos 'span.placeholder-glow' (skeleton screen) desaparecieran, agotando un timeout de 120s. La captura de pantalla muestra el gráfico renderizado pero la tabla de la derecha bloqueada con placeholders grises, coincidiendo con una respuesta de API de 19.4s en el HAR.

Posibles causas

ALTA
Lentitud extrema en API de Mercap
El HAR registra que el request a /metrics tardó 19447ms y otros dos requests de bonos superaron los 5s, indicando una respuesta lenta del backend que mantiene los placeholders activos.
MEDIA
Fallo de reactividad en el componente de UI
Aunque la API respondió eventualmente (según el HAR no hubo fallos 4xx/5xx), el componente de la tabla podría no haber procesado los datos correctamente para ocultar el estado de carga.
BAJA
Saturación de red en el runner de CI
La duración total del test (242s) es inusualmente alta, lo que podría indicar congestión general de red afectando todos los tiempos de respuesta.

Pasos de Troubleshooting

1 Verificar manualmente la carga de la curva de México en producción para descartar un problema persistente de performance.
2 Ejecutar el spec localmente: TARGET_ENV=production TARGET_CLIENT=argentina MODE=only SPEC=sanity_curvas npm run test
3 Validar el tiempo de respuesta del endpoint específico mediante curl: curl -w "%{time_total}\n" -o /dev/null -s https://api.mercapabbaco.com/yield-curves/86a282be-f60d-4cd6-be14-b1fd2871ba9b/metrics
4 Revisar logs de backend en Datadog para identificar cuellos de botella en el cálculo de métricas de curvas soberanas mexicanas.
5 Analizar si el selector span.placeholder-glow en commands.js:641 requiere un timeout aún mayor o una estrategia de espera basada en el request de red (cy.wait).
