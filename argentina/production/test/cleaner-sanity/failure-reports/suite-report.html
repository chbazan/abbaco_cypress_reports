Descripción detallada

El test falló al intentar seleccionar una curva específica dentro del flujo de 'Curvas Argentina'. Tras hacer clic en el filtro 'Todas', Cypress esperó 60 segundos por un elemento '<a>' que contuviera el texto exacto 'Corporativos - Bancos Comerciales - Tasa TAMAR'. La captura de pantalla muestra que la lista de curvas se cargó correctamente, pero el texto buscado no coincide con las opciones visibles (se observa 'Corporativos - Bancos Comerciales - USD' y 'Corporativos - ONs TAMAR - ARS', pero no la combinación solicitada).

Posibles causas

ALTA
Cambio de nombre en la UI/API
La captura de pantalla muestra 'Corporativos - Bancos Comerciales - USD'. Es muy probable que la curva haya sido renombrada y el test mantenga el string anterior 'Tasa TAMAR'.
MEDIA
Filtro de datos en la API
Si la curva no tiene bonos activos o datos de mercado suficientes, la API de Mercap podría no estar devolviéndola en el listado general.
BAJA
Sensibilidad a mayúsculas/espacios
El comando .contains() es sensible al texto exacto si no se usa regex; un cambio menor en el espaciado del componente podría causar el fallo.

1 Ejecutar localmente para inspeccionar el DOM: TARGET_ENV=production TARGET_CLIENT=argentina npx cypress open --config specPattern=**/curvas.js

3 Validar manualmente en https://bonds.mercapabbaco.com/curves si la curva 'Tasa TAMAR' aparece bajo el filtro 'Todas'.
4 Comparar el string definido en el archivo 'build/production/argentina/flows/sanity/curvas.js:32' con los elementos del listado actual.
