Descripción detallada

El test 'Validar que se muestren todas las curvas esperadas en la pestaña Todas' falló al intentar localizar el elemento '.ball-loader'. Según el screenshot, la interfaz ya ha renderizado completamente la lista de curvas (BOPREALS, Corporativos, etc.), lo que indica que la carga de datos finalizó antes de que Cypress intentara capturar el spinner. El error ocurre en 'commands.js:554', sugiriendo que existe un comando de sincronización que exige la aparición obligatoria del loader para continuar, el cual no se mostró debido a la rapidez de la respuesta de la API.

Posibles causas

ALTA
Sincronización basada en elemento inexistente
El mensaje 'Expected to find element: .ball-loader, but never found it' confirma que el test buscaba que el elemento existiera en el DOM. El screenshot muestra la grilla cargada, validando que el proceso de carga ya terminó.
MEDIA
Condición de carrera (Race Condition)
La API de Mercap respondió tan rápido (0 requests lentas en HAR) que React omitió el estado de 'loading' en el DOM, rompiendo el flujo del test que esperaba ese cambio de estado.

Pasos de Troubleshooting

1 Reproducir el fallo localmente: TARGET_ENV=production TARGET_CLIENT=argentina SPEC=cypress/e2e/curvas.cy.js npx cypress run
2 Inspeccionar el archivo 'cypress/support/commands.js' en la línea 554 para revisar la implementación del comando de espera.
3 Verificar en el video del test si el loader llega a parpadear o si la transición es directa a los datos.
4 Validar si el comando debería usar '.should("not.exist")' en lugar de una búsqueda de existencia si la intención era esperar a que termine la carga.
