Descripción detallada

El test 'Ingreso a la curva Paraguay' falló al intentar validar la visibilidad de un enlace de sección. La ejecución se detuvo tras 90s de reintentos porque el elemento estaba cubierto por un modal de clase 'session-evicted-modal'. La evidencia de red muestra una petición fallida a la API de Mercap con status 401 y el mensaje 'Token revoked', lo que disparó el cierre de sesión forzado en la interfaz.

Posibles causas

ALTA
Concurrencia de sesiones
El mismo usuario de test podría estar siendo utilizado en otra ejecución paralela, lo que invalida el token previo según la política de Abbaco.
MEDIA
Expiración o revocación de token Auth0
El token almacenado por cy.session fue revocado por el backend de Mercap (401 Unauthorized) durante la navegación.
BAJA
Inconsistencia en caché de sesión
Cypress restauró una sesión cuya cookie o token ya no es válido en el ambiente de producción.

Pasos de Troubleshooting

1 Verificar si hay otros jobs de CI corriendo simultáneamente con las mismas credenciales de test.
2 Reproducir localmente forzando un login fresco: TARGET_ENV=production TARGET_CLIENT=argentina SPEC=curvas.cy.js npm run test
3 Verificar en el dashboard de Auth0 si el usuario de test presenta múltiples logins o revocaciones recientes.
4 Validar el endpoint de mercados con el token obtenido manualmente para confirmar si el 401 es persistente.
5 Revisar si el comando cy.SessionAbbaco() está manejando correctamente la validación de la sesión antes de cada test.
