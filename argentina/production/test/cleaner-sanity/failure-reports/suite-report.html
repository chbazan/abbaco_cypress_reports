Descripción detallada

El test 'Cleaner > Eliminar los portafolios creados' estaba en ejecución, probablemente intentando limpiar portafolios de usuario después de un login exitoso. El fallo ocurrió tempranamente en el test, con una duración de 8470ms, durante una solicitud de red interceptada por Cypress. El mensaje de error 'Socket closed before finished writing response' indica un problema de conexión de red de bajo nivel. La interfaz de usuario de la aplicación se encontraba en un estado de carga, mostrando un spinner 'ball-loader', lo que sugiere que un recurso crítico no pudo cargarse completamente.

Posibles causas

ALTA
Problema de conectividad de red o infraestructura.
El error 'Socket closed before finished writing response' es un indicio claro de que la conexión TCP se cerró inesperadamente antes de que la respuesta completa pudiera ser enviada o recibida. Esto apunta a un fallo en el servidor, en la red entre el cliente y el servidor, o en el proxy/interceptor de Cypress. La duración corta del test (8.4s) refuerza que fue un fallo abrupto de conexión.
MEDIA
Fallo en el servicio de 'pd.mercapabbaco.com/flags/' o servicio relacionado.
La imagen muestra un POST request a 'https://pd.mercapabbaco.com/flags/' que es un dominio de Mercap Abbaco. Si este request fue el interceptado y falló a nivel de socket, podría indicar un problema en el servicio que lo maneja. El DOM muestra la aplicación en estado de carga, lo que podría depender de la respuesta de este tipo de requests iniciales.
BAJA
Configuración incorrecta del interceptor de Cypress.
Aunque el error se origina en el código de test ('originated from your test code'), la causa raíz es un 'network error'. Es menos probable que un interceptor mal configurado cause un cierre de socket tan específico, a menos que esté manipulando la conexión de una manera inusual. Sin embargo, es una posibilidad a considerar si las causas de red directas se descartan.

Pasos de Troubleshooting

1 Verificar el estado de los servicios de Abbaco y Mercap en el ambiente de producción (Datadog/logs).
2 Reproducir el spec localmente en el ambiente de producción: TARGET_ENV=production TARGET_CLIENT=argentina MODE=only SPEC=cleaner/cleaner npm run test
3 Abrir la aplicación manualmente en https://bonds.mercapabbaco.com/security-position en Firefox y verificar si carga correctamente y si la funcionalidad de portafolios es accesible.
4 Revisar los logs del servidor para el endpoint 'pd.mercapabbaco.com/flags/' o cualquier otro endpoint que el test esté interceptando en el momento del fallo.
5 Deshabilitar temporalmente el 'cy.intercept' relevante en el test para ver si el error persiste, lo que ayudaría a aislar si el problema es del interceptor o de la red subyacente.
