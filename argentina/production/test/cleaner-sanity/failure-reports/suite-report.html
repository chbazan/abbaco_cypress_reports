Descripción detallada

El flujo 'Validar que se muestren todas las curvas esperadas en la pestaña Todas' falló al intentar localizar el elemento '.ball-loader'. La duración de 99819ms indica que Cypress agotó el timeout de 90s esperando que el loader apareciera. El screenshot muestra la lista de curvas ya renderizada (v1.41.0), sugiriendo que la carga fue instantánea o el selector de carga cambió.

Posibles causas

ALTA
Carga de datos instantánea
El HAR indica 0 requests lentos. Si la API respondió en milisegundos, el loader pudo no haber llegado a montarse en el DOM antes de la ejecución del comando.
MEDIA
Selector de carga desactualizado
La versión v1.41.0 podría haber reemplazado '.ball-loader' por otro componente (como placeholders), haciendo que el test espere un elemento inexistente.
