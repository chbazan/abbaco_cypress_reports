Descripción detallada

El test 'Validar que se muestren todas las curvas esperadas en la pestaña Todas' falló al intentar localizar el spinner de carga '.ball-loader'. Según el screenshot y el log de Cypress, la página ya había cargado exitosamente 26 elementos de la lista de curvas ('.list-group a'). El error ocurre en un comando personalizado en 'commands.js:296', lo que indica una falla de sincronización donde el test espera obligatoriamente un elemento visual que no se renderizó o desapareció antes de la inspección.

Posibles causas

ALTA
Race condition en la carga
La API de Mercap respondió tan rápido que el componente de carga no llegó a ser capturado por el comando cy.get() dentro del ciclo de reintentos, resultando en un timeout de 90000ms.
MEDIA
Selector de carga desactualizado
Se pudo haber reemplazado '.ball-loader' por otro componente (como 'placeholder-glow') en una actualización reciente de la UI de Abbaco, haciendo que el selector viejo nunca se encuentre.

Pasos de Troubleshooting

1 Reproducir el fallo localmente: TARGET_ENV=production TARGET_CLIENT=argentina MODE=only SPEC=sanity_curvas npm run test
2 Inspeccionar el archivo 'cypress/support/commands.js' en la línea 296 para verificar la aserción aplicada al loader.
3 Verificar manualmente en el navegador si el elemento '.ball-loader' sigue existiendo durante las transiciones de carga en el módulo Curvas.
4 Revisar si el comando de espera puede ser reemplazado por un cy.intercept() para esperar el fin de la petición de red en lugar de un elemento visual efímero.
