Descripción detallada

El flujo ejecutaba la validación de curvas en la pestaña 'Todas' de Curvas Argentina. El fallo ocurre en un comando personalizado (commands.js:296), probablemente un helper de espera de carga, que intentó localizar el selector '.ball-loader'. La screenshot muestra que la página ya está completamente cargada con la lista de bonos visible, lo que sugiere que el loader desapareció antes de que Cypress iniciara la búsqueda o nunca se renderizó debido a una respuesta rápida de la API.

Posibles causas

ALTA
Race condition entre carga de UI y ejecución de test
La API respondió tan rápido que el spinner se mostró y ocultó en milisegundos, haciendo que cy.get('.ball-loader') fallara al no encontrar el elemento en el DOM durante los 90s de reintento.
MEDIA
Cambio de selector de loading
Una actualización reciente de la UI podría haber cambiado la clase '.ball-loader' por otro componente de carga (ej. un skeleton o placeholder-glow).
BAJA
Estado de sesión/cache
Los datos de las curvas podrían estar cacheados en el navegador, evitando que se dispare el estado de carga (loading state) que el test espera capturar.

Pasos de Troubleshooting

1 Reproducir localmente el fallo: TARGET_ENV=production TARGET_CLIENT=argentina MODE=only SPEC=sanity_curvas.cy.js npm run test
2 Revisar la línea 296 de cypress/support/commands.js para confirmar si el comando exige que el loader sea visible (.should('be.visible')).
3 Inspeccionar el DOM manualmente en la pestaña Curvas para verificar si el selector '.ball-loader' sigue existiendo.
4 Verificar en el HAR si la request a 'api.mercapabbaco.com/yield-curves' fue inmediata (status 200), lo que confirmaría la carga instantánea.
