Posibles causas

ALTA

MEDIA
Bug de UI en manejo de estados

No se observan errores de red (4xx/5xx) ni requests lentas en el HAR.

Posibles causas

ALTA
Cambio en estructura DOM/Clases
El selector li[class="d-flex justify-content-between..."] falla si cambia el orden de las clases o se agrega un espacio, patrón común en actualizaciones de estilos.
BAJA
Falta de datos en la curva
Si la lista de bonos para BOPREALs estuviera vacía, el elemento no existiría, pero el screenshot muestra datos cargados.

Pasos de Troubleshooting

1 Ejecutar en modo interactivo para inspeccionar el DOM: TARGET_ENV=production TARGET_CLIENT=argentina npm run cy:open
2 Identificar el elemento en la pestaña 'Análisis Online' y verificar sus clases actuales.
3 Sugerir reemplazo del selector por uno basado en texto o data-test-id: cy.contains('li', 'BPO27') o similar.
4 Verificar si el fallo ocurre solo en Firefox o es cross-browser.
