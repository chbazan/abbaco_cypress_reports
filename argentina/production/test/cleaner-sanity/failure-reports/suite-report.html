Timeout 60s en placeholder de BDC28 al simular inversión — API /investments devolvió 503 Service Unavailable

Descripción detallada

El test ejecutaba el flujo de simulación de inversión para la especie BDC28 dentro del módulo Analizar. Tras ingresar los datos de la simulación, la interfaz de usuario quedó bloqueada mostrando elementos de carga (span.placeholder-glow) que nunca desaparecieron. El análisis del HAR revela que dos peticiones POST consecutivas al endpoint /investments fallaron con un error 503 (Service Unavailable), lo que impidió que el frontend recibiera los datos necesarios para renderizar el cashflow y ocultar los placeholders.

Posibles causas

ALTA
Indisponibilidad del microservicio de inversiones
El HAR muestra dos respuestas 503 Service Unavailable para el endpoint /investments en producción, lo cual es un error de servidor directo.
MEDIA
Manejo de errores insuficiente en el frontend
La UI no mostró un mensaje de error amigable ante el fallo 503 y mantuvo los placeholders activos indefinidamente hasta el timeout de Cypress.

Pasos de Troubleshooting

1 Verificar el estado de salud del microservicio de inversiones en Datadog o Grafana para el ambiente de producción.
2 Intentar reproducir manualmente la simulación de BDC28 en https://bonds.mercapabbaco.com/bond-analysis/BYMA/BDC28.
3 Ejecutar el spec de forma aislada: TARGET_ENV=production TARGET_CLIENT=argentina MODE=only SPEC=sanity_analizar npm run test
4 Revisar los logs de la API de Mercap para identificar la causa del 503 (ej: saturación de pool de conexiones o caída de instancia).
