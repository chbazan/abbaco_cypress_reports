Fallo de sesión (401) en Portafolio — 'session evicted' impide encontrar pestaña Proyección

Descripción detallada

El test falló al intentar acceder a la pestaña de Proyección ('forecast') dentro del módulo de Portafolio. La evidencia visual (screenshot) muestra un modal de 'Error inesperado' con el mensaje 'session evicted', mientras que el HAR registra 9 errores 401 (Unauthorized) con el cuerpo 'No authorization provided'. El DOM al momento del fallo confirma que la aplicación regresó a un estado de invitado (botones 'Iniciar Sesión' visibles), donde los elementos del portafolio privado no existen.

Posibles causas

ALTA
Fallo de sesión Auth0 / cy.session
El HAR muestra múltiples errores 401 en endpoints críticos como /tradable-securities y /yield-curves. El screenshot confirma explícitamente 'session evicted', indicando que el token de acceso fue revocado o expiró.
MEDIA
Redirección inesperada a vista de invitado
Al fallar la autenticación, la app redirigió al usuario a la vista pública de AL30 (según el DOM-FALLO), donde el selector [data-rr-ui-event-key="forecast"] no está presente.

Pasos de Troubleshooting

1 Verificar manualmente el estado del login en producción: https://bonds.mercapabbaco.com/security-position
2 Reproducir el fallo localmente con la sesión activa: TARGET_ENV=production TARGET_CLIENT=argentina SPEC=sanity_portafolio npm run test
3 Revisar logs de Auth0 para el usuario de test en el timestamp 2026-07-03T18:32:33Z para identificar causas de desalojo de sesión.
4 Verificar si el comando cy.SessionAbbaco() está renovando correctamente los tokens antes de que expiren.
5 Ejecutar con modo abierto para observar el comportamiento del modal de error: npm run cy:open
