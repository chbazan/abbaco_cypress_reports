Descripción detallada

El test 'Eliminar el portafolio creado' falló al intentar localizar el selector 'svg.tabler-icon.tabler-icon-dots' en la página de Portafolio. La captura de pantalla muestra el estado 'Empty State' de la sección Mis Portafolios, con la ilustración de bienvenida y el botón '+ Nuevo portafolio' visible. Aunque se observan peticiones XHR exitosas a '/portfolios/', la interfaz no renderizó ninguna fila de datos, lo que provocó que Cypress agotara el timeout de 60 segundos buscando el elemento para iniciar el flujo de borrado.

Posibles causas

ALTA
Fallo en la precondición de creación
El portafolio que el test intenta eliminar no se creó correctamente en los pasos previos del spec, dejando la cuenta en estado vacío.
MEDIA
Respuesta de API vacía
El endpoint 'GET /portfolios/' devolvió un array vacío [] a pesar de que el recurso debería existir, posiblemente por un problema de persistencia o latencia en la base de datos de Mercap.
BAJA
Cambio de selector en la UI
Se modificó la clase o el componente del icono de tres puntos (dots) en una actualización reciente del frontend, aunque el screenshot sugiere que el problema es la falta de datos.

Pasos de Troubleshooting

1 Verificar si el test de creación de portafolio previo en el mismo spec fue exitoso.
2 Ejecutar localmente: TARGET_ENV=production TARGET_CLIENT=argentina SPEC=sanity/portafolio.js npx cypress run
3 Inspeccionar el body de la respuesta de 'GET https://api.mercapabbaco.com/portfolios/' en el archivo HAR para confirmar si el array de portafolios está vacío.
4 Acceder manualmente a la plataforma con las credenciales de test para verificar si el usuario tiene portafolios visibles.
5 Revisar logs de la API de Mercap para el owner específico durante el timestamp del fallo.
