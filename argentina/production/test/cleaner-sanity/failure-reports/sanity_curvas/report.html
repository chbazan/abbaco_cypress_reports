El test 'Validar que se muestren todas las curvas esperadas en la pestaña Todas' falló al no encontrar el texto 'Soberanos - Letras del Tesoro vinculadas al u$s (LELINK) - ARS' dentro del listado de curvas (.list-group a). El análisis del HAR confirma que la API /yield-curves respondió exitosamente (200 OK) en 130ms, lo que descarta problemas de red o timeouts de carga.

Posibles causas

ALTA
Curva LELINK ausente en el payload de la API
El test falló rápidamente (9.8s) tras una respuesta exitosa de la API. Si el instrumento fue dado de baja o no tiene datos suficientes para generar la curva, la API no lo devuelve y el test falla por aserción de contenido.
MEDIA
Renombramiento del instrumento en el backend
Cambios en la nomenclatura de las letras del tesoro en la API de Mercap invalidan las aserciones de texto exacto en el frontend si el test no está actualizado.
BAJA
Filtro de UI inesperado
Un cambio en la lógica de filtrado de la pestaña 'Todas' podría estar ocultando instrumentos específicos, aunque es menos probable que una falta de datos.

Pasos de Troubleshooting

1 Verificar manualmente en https://bonds.mercapabbaco.com/curves si la curva LELINK aparece en la pestaña 'Todas'.
2 Inspeccionar el JSON de respuesta de GET https://api.mercapabbaco.com/yield-curves en el HAR para buscar el string 'LELINK'.
3 Reproducir localmente: TARGET_ENV=production TARGET_CLIENT=argentina SPEC=sanity_curvas npm run test
