Descripción detallada

El test 'Anuncios > Validar el modal' falló al no encontrar el elemento 'div.offcanvas.offcanvas-end.show' tras agotar el timeout de 90 segundos. La captura de pantalla muestra un viewport completamente vacío (fondo gris oscuro), lo que indica que la aplicación no renderizó la interfaz de usuario. El análisis del HAR confirma que todas las peticiones a la API de Mercap (tradable-securities, metrics, yield-curves) devolvieron status 200 OK en menos de 220ms, descartando un problema de red.

Posibles causas

ALTA
Error de renderizado de UI (JS Crash)
El screenshot muestra una pantalla gris sin elementos. Dado que la red respondió correctamente, es probable que un error de JavaScript haya detenido el ciclo de vida de React/Vue antes de pintar la interfaz.
MEDIA
Incompatibilidad con Firefox Headless
El fallo ocurre específicamente en Firefox. Ciertos componentes de Bootstrap (offcanvas) o animaciones de CSS pueden comportarse de forma inconsistente en este navegador si no se gestionan correctamente los tiempos de renderizado.
BAJA
Estado de sesión inconsistente
Aunque cy.session() parece haber funcionado, un token mal formado o expirado podría causar que la app no sepa qué vista renderizar, aunque el HAR no muestra errores 401/403.

Pasos de Troubleshooting

1 Reproducir el spec localmente: TARGET_ENV=production TARGET_CLIENT=argentina MODE=only SPEC=sanity_02_notifications npm run test
2 Ejecutar en modo 'headed' con Firefox para observar si hay errores visibles en la consola del desarrollador.
3 Verificar si el anuncio/notificación está configurado como activo en el CMS para el ambiente de producción.
4 Revisar los logs de Mixpanel para confirmar si el evento de 'viewed notification' se disparó antes del timeout.
5 Validar si el error persiste en Chrome para descartar un problema específico del motor Gecko.
