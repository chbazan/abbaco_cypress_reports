Timeout 90s en .text-success en Sensibilidad — Interrupción del flujo por Network Error al agregar escenario

Descripción detallada

El test ejecutaba el flujo de agregar un escenario en el módulo de Sensibilidad. Falló esperando la visibilidad del elemento '.text-success' (confirmación de éxito). La screenshot revela un banner crítico 'Oh no! Algo salió mal - Network Error', lo que confirma que la acción de guardado o la carga de datos previa falló catastróficamente.

Posibles causas

ALTA
Fallo en el POST de creación de escenario
La aparición del banner de error coincide con el paso de validación de éxito, sugiriendo que la petición de red para crear el escenario falló.
MEDIA
Inestabilidad general de la API en producción
Ambos fallos en el run (Screener y Sensibilidad) presentan banners de 'Network Error', indicando un problema sistémico de conectividad con los servicios de Mercap.

Pasos de Troubleshooting

1 Reproducir el fallo localmente: TARGET_ENV=production TARGET_CLIENT=argentina MODE=only SPEC=smoke/sensibilidad npm run test
2 Verificar en el HAR la respuesta exacta de la petición POST a /sensibilidad o similar
3 Comprobar si el módulo de Sensibilidad funciona manualmente en producción
4 Analizar si hay errores 5xx reportados en el dashboard de infraestructura de la API
