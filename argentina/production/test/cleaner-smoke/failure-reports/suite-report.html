Timeout 90s en Screener: 'Network Error' al cargar catálogo de Leyes impide selección de filtro

Descripción detallada

El test falló durante el flujo de filtrado en el Screener al intentar interactuar con el selector de 'Ley'. Según el screenshot, la aplicación muestra un banner rojo de 'Network Error' indicando un fallo al obtener las leyes. El elemento 'Seleccionar Ley' nunca se renderizó, dejando el campo bloqueado con un placeholder gris, lo que provocó el agotamiento del defaultCommandTimeout de 90000ms.

Posibles causas

ALTA
Fallo en endpoint de metadatos/leyes
La UI muestra explícitamente 'Ocurrió un error al obtener Ley'. Aunque el resumen del HAR indica 0 fallidos, es probable que la petición haya fallado por timeout de red o devuelto un cuerpo vacío/error con status 200.
MEDIA
Inestabilidad temporal en API Mercap
La duración total del test (180s) y el mensaje de error de red sugieren que el ambiente de producción experimentó latencia o intermitencia durante la carga inicial de catálogos.

Pasos de Troubleshooting

1 Reproducir el fallo localmente: TARGET_ENV=production TARGET_CLIENT=argentina MODE=only SPEC=smoke_screener npm run test
2 Inspeccionar el HAR completo para identificar el endpoint específico que carga las leyes (ej: /metadata o /laws)
3 Verificar logs de errores en Sentry o Datadog para la API api.mercapabbaco.com en el timestamp del fallo
4 Validar manualmente en la web de producción si el módulo Screener carga correctamente los selectores de Ley y Moneda
5 Revisar si hubo un deploy reciente que haya modificado la estructura de respuesta de los catálogos del Screener
