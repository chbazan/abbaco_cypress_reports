ALTA
Fallo en la selección de la segunda especie.
El DOM al momento del fallo muestra el input de la segunda especie vacío y el botón 'Arbitrar' deshabilitado, lo que impide que se genere el gráfico.
MEDIA
El botón 'Arbitrar' no se habilitó o no se pudo hacer clic.
Aunque la segunda especie se hubiera seleccionado, si el botón permanece deshabilitado o el clic no se registra, el gráfico no se cargará. El DOM muestra el botón 'Arbitrar' con el atributo 'disabled'.
BAJA
Problema de renderizado de Highcharts.
Menos probable dado que la UI no llegó al estado donde el gráfico debería renderizarse (el mensaje 'Empiece su búsqueda...' sigue visible y el botón 'Arbitrar' está deshabilitado).
