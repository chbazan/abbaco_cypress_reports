Descripción detallada

El test ejecutaba la validación de especies favoritas en el Home (smoke_favoritos). Falló al no encontrar el contenido 'LECHO' dentro del contenedor de favoritos tras 60s de reintentos (AssertionError). En la screenshot se observan las tarjetas de PECMO, AL30, BDC28 y TX28, pero la especie LECHO no está presente en la lista renderizada.

Posibles causas

ALTA
Especie no marcada como favorita
El test asume que LECHO es favorita, pero la UI solo muestra otras 4 especies. Puede ser un fallo en la pre-condición del test o en la persistencia de favoritos del usuario.
MEDIA
Problema de paginación/carrusel en UI
LECHO podría estar en una posición no visible del carrusel (flecha derecha visible en screenshot) y el comando de Cypress no realizó el scroll necesario antes de la aserción.

Pasos de Troubleshooting

1 Reproducir localmente: TARGET_ENV=production TARGET_CLIENT=argentina SPEC=smoke/favoritos.cy.js npm run test
2 Verificar manualmente en la app si la especie LECHO aparece marcada con estrella en el módulo Curvas
3 Revisar el response de la API de favoritos para confirmar si LECHO está incluido en el JSON de respuesta
4 Ejecutar npm run analyze-failure -- smoke_favoritos para revisar el video y ver si hubo un error previo al setear favoritos
