Descripción detallada

El test 'Screener ARG > Selecciona YPF S.A. en "Seleccionar Emisor"' intentaba interactuar con el selector de emisores. Falló al intentar encontrar el texto 'Seleccionar Emisor' dentro del dropdown, agotando el timeout de 90 segundos. La UI mostraba un mensaje de 'Network Error' indicando un fallo al obtener los emisores, y el campo 'Emisor' presentaba un placeholder en lugar del dropdown interactivo. La duración total del test fue de 180970ms, lo que sugiere que el timeout de 90s se agotó en el paso de búsqueda del elemento.

Posibles causas

ALTA
Fallo en la API de Mercap al obtener emisores
El mensaje de error en la UI 'Network Error: Ocurrió un error al obtener Emisor' y la presencia de un placeholder en el campo 'Emisor' en el DOM y screenshot confirman que la carga de datos falló.
MEDIA
Timeout de la API de emisores
La duración del test de 180970ms y el mensaje 'Timed out retrying after 90000ms' sugieren que Cypress esperó el tiempo máximo para que el elemento apareciera, lo que podría ser causado por una respuesta de API extremadamente lenta que nunca llegó o llegó tarde.
BAJA
Problema de renderizado del componente 'Emisor' tras una respuesta de API vacía o malformada
Es posible que la API haya respondido con un cuerpo inválido o vacío que el componente no pudo procesar, llevando al estado de error y placeholder, aunque la UI indica explícitamente un 'Network Error'.

Pasos de Troubleshooting

1 Reproducir el spec fallido localmente: TARGET_ENV=production TARGET_CLIENT=argentina MODE=only SPEC=smoke/screener npm run test
2 Abrir la aplicación manualmente en https://bonds.mercapabbaco.com/bond-screener en el ambiente de producción y verificar si el campo 'Emisor' carga correctamente o si muestra el 'Network Error'.
3 Inspeccionar las llamadas de red en el navegador (DevTools) al cargar el Screener para identificar el endpoint que carga los emisores y su estado/tiempo de respuesta.
4 Si se identifica el endpoint, verificar su estado con una herramienta como curl o Postman directamente a la API de Mercap.
