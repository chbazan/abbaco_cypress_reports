Descripción detallada

El test 'Cleaner > Eliminar todas las curvas favoritas' falló durante un paso de aserción. El test esperaba encontrar el contenido 'Curvas Favoritas' (con 'F' mayúscula) dentro del selector 'div.text-body.fw-bold' anidado en un 'div.card-body', pero no lo encontró tras 10 segundos de reintentos. La evidencia del DOM al momento del fallo muestra que el elemento 'div.text-body.fw-bold' en la tarjeta de 'Curvas favoritas' contiene el texto 'Agregá favoritos'. La captura de pantalla confirma que la sección 'Bonos favoritos' estaba poblada, mientras que la sección 'Curvas favoritas' mostraba su estado vacío.

Posibles causas

ALTA
Contenido de aserción incorrecto en el test
El mensaje de error 'Expected to find content: 'Curvas Favoritas' ... but never did' y el DOM-FALLO demuestran que el selector 'div.text-body.fw-bold' contiene 'Agregá favoritos', no 'Curvas Favoritas'. Hay un mismatch de texto y/o capitalización.
MEDIA
Selector de elemento incorrecto en el test
El texto 'Curvas favoritas' (con 'f' minúscula) se encuentra en el título 'h6' de la tarjeta, no en el 'div.text-body.fw-bold' que es el elemento de contenido del estado vacío. El test podría estar apuntando al elemento equivocado para el texto esperado.
BAJA
Fallo silencioso en la eliminación de favoritos
La captura de pantalla muestra la sección 'Bonos favoritos' con elementos aún presentes (PECMO, TX28, BDC28, AL30), a pesar de que el test se llama 'Eliminar todas las curvas favoritas'. Esto podría indicar que la acción de eliminación no se ejecutó correctamente, aunque el error directo es de aserción de texto.

Pasos de Troubleshooting

1 Reproducir el spec localmente: TARGET_ENV=production TARGET_CLIENT=argentina MODE=only SPEC=cleaner/cleaner.cy.js npm run test
2 Inspeccionar el código del test 'cleaner.cy.js' en la función 'desmarcarSiguiente' (línea 1838 de 'commands.js') para verificar la aserción que busca el texto 'Curvas Favoritas' y el selector utilizado.
3 Abrir la aplicación manualmente en 'https://bonds.mercapabbaco.com/' y navegar a la sección 'Inicio' para verificar el texto exacto y la estructura HTML de la tarjeta 'Curvas favoritas' cuando está vacía y cuando tiene elementos.
4 Ajustar la aserción en el test para que busque el texto correcto ('Agregá favoritos') en el selector 'div.text-body.fw-bold' o el texto 'Curvas favoritas' en el selector 'h6.card-title div'.
