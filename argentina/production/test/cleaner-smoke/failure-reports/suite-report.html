Descripción detallada

El test 'Screener ARG > Selecciona USD en Moneda de Pago' falló al intentar interactuar con el selector de moneda. La captura de pantalla muestra un banner rojo de 'Network Error' indicando un fallo al obtener el listado de monedas desde la API. Cypress agotó el defaultCommandTimeout de 90000ms buscando el texto 'Seleccionar Moneda de Pago' que nunca se renderizó debido al error de carga del componente.

Posibles causas

ALTA
Error de red en endpoint de monedas
La UI muestra explícitamente 'Network Error: Ocurrió un error al obtener Monedas'. Esto indica que una petición crítica para el funcionamiento del Screener falló o devolvió un status no exitoso.
MEDIA
Inconsistencia en carga de datos de la API
Aunque el log de Cypress muestra peticiones GET 200 a /announcements/records, el banner de error sugiere que otra petición específica (posiblemente /currencies) falló silenciosamente antes de la interacción.

Pasos de Troubleshooting

1 Verificar manualmente en producción si el módulo Screener carga correctamente el listado de monedas.
2 Ejecutar el test localmente: TARGET_ENV=production TARGET_CLIENT=argentina SPEC=smoke_screener npm run test
3 Inspeccionar el HAR completo para identificar el endpoint exacto que falló (probablemente relacionado con /currencies o /metadata).
4 Revisar logs de la API de Mercap en el horario del fallo (2026-05-19T12:15:55Z) para detectar errores 5xx.
5 Verificar si el error es persistente o una intermitencia de red en el ambiente de producción.
