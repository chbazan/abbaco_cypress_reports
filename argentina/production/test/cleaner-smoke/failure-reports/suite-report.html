Descripción detallada

El test 'Ingreso en Análisis online de la primera curva de la lista' falló al intentar localizar un elemento de lista específico. Según el screenshot, la aplicación cargó correctamente los datos en una tabla, pero el test busca un elemento 'li' con clases de Bootstrap (list-group-item). La duración de 90000ms en el comando fallido indica que Cypress esperó la aparición del elemento hasta agotar el timeout, a pesar de que la UI ya mostraba información.

Posibles causas

ALTA
Cambio en la estructura del DOM
El selector CSS es extremadamente específico y depende de múltiples clases de estilo. Si el componente fue refactored de una lista a una tabla, el selector 'li' dejará de funcionar.
MEDIA
Diferencia de Viewport (Mobile vs Desktop)
Las clases 'd-flex justify-content-between' en un 'li' son típicas de vistas mobile. Si el test se ejecutó en una resolución desktop (1920x1200 según el header), la app podría estar mostrando la versión de tabla en lugar de la lista.

Pasos de Troubleshooting

1 Ejecutar el test localmente con la interfaz de Cypress para inspeccionar el DOM: npx cypress open
2 Verificar si el selector li[class*='list-group-item'] existe en la versión desktop de la página de curvas
3 Comparar el código del Page Object con la estructura actual de la tabla de 'Análisis Online'
4 Validar si el test requiere una resolución específica (viewport) para que ese selector sea válido
5 Revisar logs de despliegue recientes para identificar cambios en el componente de grilla de bonos
