Descripción detallada

El test falló durante la ejecución del flujo de Screener ARG al intentar seleccionar la moneda de pago. Posibles causas

ALTA

A pesar de que el resumen de red indica 0 fallos, la UI muestra explícitamente un banner de 'Network Error'. Esto ocurre frecuentemente cuando la API devuelve un 200 con un cuerpo de error o una respuesta vacía inesperada.
MEDIA
Inestabilidad en el endpoint de anuncios/monedas
El screenshot muestra que el componente de 'Moneda de pago' está grisado (deshabilitado), síntoma de que la petición inicial a la API de Mercap no completó la carga de opciones.

La screenshot revela un banner de error crítico ('Oh no! Algo salió mal - Network Error') y una tabla de resultados vacía, confirmando que la operación de backend falló o no respondió a tiempo.
