Descripción detallada

El test falló al intentar interactuar con el campo 'Ley' en el flujo del Screener. Se observa un banner de 'Network Error' en la parte superior de la UI y el campo 'Ley' permanece bloqueado con un componente de carga ('placeholder-glow'). Cypress agotó el timeout de 90000ms esperando encontrar el texto 'Seleccionar Ley', el cual nunca se renderizó debido al fallo en la obtención de datos.

Posibles causas

ALTA
Error de red o 5xx en el endpoint de catálogos de leyes
La UI muestra explícitamente un banner de 'Network Error' con el mensaje 'Ocurrió un error al obtener Ley'. El DOM confirma la presencia de un elemento 'placeholder' en lugar del dropdown esperado.
MEDIA
Timeout de respuesta de la API de Mercap
Si la API tardó más de lo que el frontend espera para resolver la promesa de carga, el componente puede quedar en estado de placeholder permanentemente.
BAJA
Regresión en el manejo de errores del frontend
El error es capturado pero el estado de carga no se limpia, impidiendo que el test (o el usuario) pueda reintentar la acción sin recargar la página.

Pasos de Troubleshooting

1 Verificar disponibilidad del endpoint de leyes: curl -I https://api.mercapabbaco.com/laws (o similar)
2 Reproducir el fallo localmente: TARGET_ENV=production TARGET_CLIENT=argentina SPEC=smoke/screener.js npm run test
3 Inspeccionar el HAR completo para identificar el status code y response body del request fallido relacionado con 'Ley'
4 Revisar logs en Sentry/Datadog filtrando por el mensaje 'Ocurrió un error al obtener Ley'
5 Verificar si hay problemas de infraestructura reportados en el ambiente de producción de Mercap
