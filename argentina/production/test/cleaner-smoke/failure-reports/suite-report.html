Timeout 90s en selector de edición de precio simulado en Calculadora — elemento no encontrado en la tabla.

Descripción detallada

El test ejecutaba el flujo de edición de una simulación en el módulo de Calculadora. Falló en el paso de interacción con la celda de precio al no encontrar el botón con clases 'editable-value' dentro del alias '@celdaPrecio'. La duración de 92267ms confirma que Cypress agotó el timeout de reintento esperando que el elemento apareciera en el DOM.

Posibles causas

ALTA
Cambio en la UI/Clases CSS
El selector 'button.editable-value.cursor-pointer...' no coincide con el estado actual del DOM, aunque la tabla parece estar cargada correctamente en el screenshot.
MEDIA
Estado de edición no activado
El componente podría requerir una acción previa (hover o click) para renderizar el botón de edición que el test no logró disparar o detectar.

Pasos de Troubleshooting

1 Reproducir localmente: TARGET_ENV=production TARGET_CLIENT=argentina MODE=only SPEC=smoke/calculadora npm run test
2 Inspeccionar el DOM en el navegador para verificar las clases actuales del botón de edición en la tabla de simulaciones.
3 Verificar en el reporte de Cypress si el alias '@celdaPrecio' está seleccionando el contenedor correcto antes del 'find'.
4 Ejecutar npm run cy:open para observar el comportamiento del componente en tiempo real.

Error de red al cargar monedas en Screener — banner de error visible impide selección de Moneda de Pago.

Descripción detallada

El test intentaba filtrar bonos por 'Moneda de Pago' en el Screener. Falló al no encontrar el texto 'Seleccionar Moneda de Pago' tras 90s. La captura de pantalla muestra un banner rojo de 'Network Error' indicando un fallo al obtener las monedas, lo que impidió la carga del componente de selección.

Posibles causas

ALTA
Error 5xx/4xx en API de Monedas
El mensaje 'Ocurrió un error al obtener Monedas' en la UI es evidencia directa de un fallo en la comunicación con el backend de Mercap.
MEDIA
Latencia extrema en el servicio de Screener
Si la API tardó más de lo que el frontend espera para el recurso de monedas, se dispara el estado de error de red visible en el screenshot.

Pasos de Troubleshooting

1 Verificar disponibilidad del ambiente: abrir https://bonds.mercapabbaco.com/bond-screener manualmente.
2 Revisar el HAR detallado para identificar el código de estado (4xx/5xx) del endpoint de currencies.
3 Verificar logs de Datadog/Sentry para el servicio api.mercapabbaco.com en el timestamp del fallo.
