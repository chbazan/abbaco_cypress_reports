Error de interactividad: botón 'Simular' cubierto por 'offcanvas-header' en el panel lateral de simulación.

Descripción detallada

El flujo 'Simular inversiones de la especie AL30' falló al intentar ejecutar cy.click() sobre el botón de simulación. Cypress detectó que el elemento estaba cubierto por el encabezado del panel lateral (offcanvas-header) durante 60 segundos. El screenshot confirma que el panel lateral está desplegado, pero el botón 'Crear simulación' parece estar fuera del área de interacción o solapado por el layout.

Posibles causas

ALTA
Solapamiento de UI por scroll
Cypress intenta centrar el botón para clickearlo, pero el header fijo del offcanvas lo cubre. El error cita explícitamente a 'offcanvas-header' como el elemento bloqueante.
MEDIA
Layout responsivo en Firefox
Diferencias de renderizado en Firefox headless pueden causar que el contenedor del formulario no calcule correctamente el espacio disponible, empujando el botón bajo el header.

Pasos de Troubleshooting

1 Reproducir localmente con interfaz: TARGET_ENV=production TARGET_CLIENT=argentina npx cypress open
2 Verificar si el botón es clickeable manualmente en la URL https://bonds.mercapabbaco.com/calculator
3 Ejecutar el test con una resolución mayor para descartar problemas de viewport
4 Probar el uso de {force: true} en el comando cy.click() como solución temporal
5 Revisar si el comando .scrollIntoView() antes del clic resuelve el solapamiento
