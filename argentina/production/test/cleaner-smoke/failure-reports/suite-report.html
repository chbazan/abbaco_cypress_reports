Descripción detallada

El test 'Verificar que todas las curvas eliminadas no se muestren más como favoritas en el menú Curvas' en el spec 'smoke_favoritos' falló al validar la eliminación de curvas de favoritos. El fallo ocurrió en el paso donde Cypress esperaba que el ícono de estrella de favorito (<svg.tabler-icon.tabler-icon-star-filled.text-warning>) no existiera en el DOM. Sin embargo, el elemento fue encontrado continuamente durante 90000ms, agotando el defaultCommandTimeout. La duración total del test fue de 191778ms, y el HAR no reporta fallos ni lentitud en las peticiones de red, lo que sugiere un problema de sincronización de estado o renderizado.

Posibles causas

ALTA
La acción de 'eliminar de favoritos' no se procesó correctamente en el backend.
El test espera que el elemento `<svg.tabler-icon.tabler-icon-star-filled.text-warning>` no exista, pero fue encontrado continuamente durante 90 segundos. Esto sugiere que la curva no fue eliminada de la lista de favoritos o su estado no se actualizó. El HAR no muestra errores de red (4xx/5xx), lo que podría indicar que la petición se envió y recibió un 200 OK, pero la lógica interna del servidor no actualizó el estado.
MEDIA
Fallo en la actualización del estado del frontend o en el re-renderizado del componente de la lista de curvas.
Si el backend procesó correctamente la eliminación, el frontend podría no haber invalidado su caché de datos o no haber re-renderizado la lista de curvas para reflejar el nuevo estado, manteniendo el ícono de estrella visible. El DOM al momento del fallo y el screenshot confirman la presencia de las estrellas.
MEDIA
Desincronización entre el estado de la aplicación y la UI.
Podría haber un problema con el store de Redux/Zustand o el cache de React Query que no se invalidó o actualizó correctamente después de la acción de eliminar un favorito, haciendo que la UI muestre un estado obsoleto.

Pasos de Troubleshooting

1 Reproducir el spec fallido localmente con `TARGET_ENV=production TARGET_CLIENT=argentina MODE=only SPEC=smoke/favoritos npm run test` para observar el comportamiento de la UI y la consola del navegador.
2 Abrir la aplicación manualmente en `production/argentina`, navegar a la sección 'Curvas', marcar una curva como favorita, luego intentar eliminarla y verificar visualmente si la estrella desaparece.
3 Monitorear las llamadas a la API (especialmente las relacionadas con `yieldCurvesService` o `favorites`) en la pestaña de red del navegador al eliminar una curva de favoritos para verificar el status code y el payload de respuesta.
4 Revisar los logs de backend relacionados con la gestión de favoritos para el ambiente de producción en Datadog o Kibana.
