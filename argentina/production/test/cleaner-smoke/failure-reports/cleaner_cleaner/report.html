Descripción detallada

El test ejecutaba el flujo de limpieza 'Cleaner > Eliminar los portafolios creados' y falló en la aserción de portafolioPage.js:74. La UI muestra la pantalla promocional de 'Mis Portafolios' con un botón de 'Prueba gratuita' en lugar de la lista de activos, indicando que el usuario no está correctamente logueado o no tiene permisos. El HAR confirma múltiples errores 401 en la API de anuncios y una respuesta extremadamente lenta (20.8s) del endpoint /authorize de Auth0.

Posibles causas

ALTA
Fallo de sesión Auth0
El HAR muestra un tiempo de respuesta de 20850ms para el authorize de Auth0 y subsiguientes errores 401 en api.mercapabbaco.com, lo que impide la carga de datos privados.
MEDIA
Usuario sin suscripción activa
La captura de pantalla muestra el mensaje 'Aumentá tu arsenal de datos' y botones de planes, sugiriendo que el usuario utilizado no tiene acceso al módulo de portafolios en producción.
BAJA
Timeout de carga de datos de portafolio
La aserción falló tras 90000ms exactos, indicando que Cypress esperó a que la UI cambiara al estado 'con datos' pero nunca sucedió debido a los errores de red.

Pasos de Troubleshooting

1 Intentar reproducción local: TARGET_ENV=production TARGET_CLIENT=argentina MODE=only SPEC=cleaner/cleaner npm run test
2 Verificar validez de credenciales en el archivo de configuración de entorno o secretos de CI/CD
3 Ejecutar 'npm run cy:open' y observar manualmente si el login de Auth0 completa el flujo correctamente
4 Verificar en el dashboard de Auth0 si hay bloqueos por IP o límites de rate limit alcanzados
5 Validar el estado de la suscripción del usuario de test en la base de datos de producción
