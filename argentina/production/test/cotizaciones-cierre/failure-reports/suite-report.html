Descripción detallada

El test falló durante la validación de la cotización de cierre del bono LECHO en el módulo de análisis. Según el log de Cypress y el screenshot, se extrajo el valor '28000.0028' del DOM, pero la aserción falló al compararlo contra el valor de referencia de '30000' (Pepper). La UI de Abbaco muestra '28.000,00', confirmando que el dato visualizado no coincide con la expectativa del test.

Posibles causas

ALTA
Desactualización de precios en API Mercap
La UI muestra un valor procesado (28000.0028) que difiere significativamente del esperado (30000). Es probable que el proceso de ingesta de cierres de BYMA no haya impactado el último valor en el backend de Abbaco.
MEDIA
Error en la fuente de referencia (Pepper)
El valor de 30000 inyectado o consultado por el test como 'esperado' podría ser incorrecto o pertenecer a una especie/plazo distinto al visualizado en la pantalla de Abbaco.
BAJA
Ajuste por corte de cupón o amortización
Si el bono LECHO tuvo un evento corporativo reciente, Abbaco podría estar mostrando el precio ajustado mientras que la referencia no, aunque la diferencia de ~7% es inusual para un error de redondeo.

Pasos de Troubleshooting

1 Verificar el precio de cierre oficial de LECHO en BYMA/Bolsar para el día de la fecha.
2 Ejecutar el test localmente: TARGET_ENV=production TARGET_CLIENT=argentina MODE=only SPEC=cotizaciones-cierre_02_check-closing-quotes-abbaco-arg.cy.js npm run test
3 Consultar el endpoint de la API de Mercap (api.mercapabbaco.com) para el bono LECHO y comparar el valor 'lastPrice' con el del DOM.
4 Revisar si existen errores de ingesta en los logs del backend de Abbaco para el proveedor de precios de Argentina.
