Timeout 90s: No se encontró vela en el gráfico de AL30 coincidente con la fecha de cierre (mismatch de fecha/label).

Descripción detallada

El test ejecutaba la validación de volumen para el bono AL30 en el módulo de análisis. El fallo ocurre al intentar localizar la barra de volumen en el gráfico de Highcharts que coincida con la fecha obtenida del popup de cotización. Aunque la UI muestra el gráfico renderizado, la aserción en 'commands.js:431' falló tras 90s porque ningún elemento SVG (path/rect) tenía un 'aria-label' que matcheara el string de fecha buscado.

Posibles causas

ALTA
Mismatch de formato de fecha
El test busca un string de fecha específico (ej: '14/05/2026') pero Highcharts puede estar usando un formato localizado o descriptivo en el aria-label (ej: 'Thursday, May 14, 2026').
MEDIA
Falta de vela del día actual
El precio de cierre corresponde a la fecha de hoy, pero el gráfico histórico de la API de Mercap podría no haber procesado o devuelto aún el último punto de datos, dejando al test buscando una fecha inexistente en el SVG.
BAJA
Diferencia de zona horaria (UTC vs Local)
La fecha del popup se extrae en hora local mientras que el gráfico podría estar renderizando etiquetas basadas en timestamps UTC, generando un desfase de un día.

Pasos de Troubleshooting

1 Reproducir localmente con: TARGET_ENV=production TARGET_CLIENT=argentina SPEC=cotizaciones-cierre_02_check-closing-quotes-abbaco-arg.cy.js npm run test
2 Inspeccionar el DOM en el punto de fallo para verificar el valor exacto del atributo 'aria-label' en los elementos 'rect.highcharts-point'.
3 Agregar un cy.log() en cypress/support/commands.js:431 para visualizar qué string de fecha está intentando matchear el test.
4 Verificar si el bono AL30 tuvo operaciones en la fecha indicada por el popup consultando directamente la API de Mercap.
5 Validar si el problema persiste en otros navegadores (Chrome) para descartar issues de localización de Firefox.
