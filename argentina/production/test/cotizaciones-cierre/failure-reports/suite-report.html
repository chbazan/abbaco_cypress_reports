Mismatch de cotización en bono LECHO: Abbaco reporta 30600.003 vs 30000 esperado de Pepper

Descripción detallada

El test 'Validar en Abbaco que la cotización de cierre del bono LECHO sea la correcta' falló durante la aserción de valor. Según el log de Cypress y el screenshot, se extrajo '30600.003' del DOM (componente Últ. Cotización), pero la validación esperaba '30000' con una tolerancia de 0.1. El fallo ocurre en la línea 1488 de commands.js tras obtener el texto del elemento 'span.me-2'.

Posibles causas

ALTA
Desincronización de precios entre Mercap y Pepper
El HAR muestra que las peticiones de red fueron exitosas (200 OK), lo que indica que la UI muestra lo que la API devuelve, pero el valor difiere de la referencia externa usada en el test.
MEDIA
Error de redondeo o precisión en el cálculo de la API
El valor extraído '30600.003' tiene una precisión de tres decimales inusual para cotizaciones de cierre, lo que podría indicar un cálculo intermedio expuesto.
BAJA
Actualización tardía del precio de cierre en el ambiente de producción
Si el mercado operó recientemente, una de las dos fuentes podría estar reflejando el precio intradiario en lugar del de cierre.

Pasos de Troubleshooting

1 Reproducir localmente: TARGET_ENV=production TARGET_CLIENT=argentina MODE=only SPEC=cotizaciones-cierre_02_check-closing-quotes-abbaco-arg npm run test
2 Verificar manualmente el valor de LECHO en la terminal de BYMA o Pepper para confirmar cuál es el correcto.
3 Consultar el endpoint de la API de Mercap para el bono LECHO (visto en el HAR) y comparar el campo de precio con el valor del DOM.
4 Revisar el reporte de fallo generado por npm run analyze-failure para descartar otros bonos con el mismo problema.
