Descripción detallada

El test 'Validar en Abbaco que la cotización de cierre del bono LECHO sea la correcta' falló al comparar el valor extraído de la UI contra la referencia externa. El comando cy.invoke('.text()') obtuvo '30600.003' del elemento 'span.me-2', pero la aserción esperaba un valor cercano a '30000' con una tolerancia de +/- 0.1. La captura de pantalla confirma que la UI muestra '30.600,00', validando que el error no es de extracción sino de discrepancia de datos.

Posibles causas

ALTA
Desactualización de precios en API Mercap
Abbaco muestra 30600.003 mientras que la referencia espera 30000. El HAR no muestra errores de red (0 fallidos), lo que indica que la API respondió correctamente pero con un dato que el test considera erróneo.
MEDIA
Ajuste por cortes o valor residual no sincronizado
El valor extraído tiene decimales específicos (30600.003) que podrían derivar de un cálculo interno de Abbaco sobre el valor residual que no coincide con la cifra redonda de la referencia.
BAJA
Diferencia de timing en el cierre de mercado
Si el test corre durante el proceso de liquidación, una fuente puede haber tomado el precio de cierre antes que la otra.
