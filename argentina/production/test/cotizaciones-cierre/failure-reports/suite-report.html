Fallo al crear simulación en Calculadora por 503 en API /investments/, dejando UI bloqueada.

Descripción detallada

El test 'Validar la cotización de cierre del bono TX28 en el campo Valor' ejecutaba un flujo en el módulo 'Calculadora'. El test interactuó con el formulario de simulación en el offcanvas y, al intentar crear una simulación, se disparó un request POST a /investments/. Este request falló con un error 503 'Service Unavailable' de la API de Mercap. Como consecuencia, la UI entró en un estado inesperado, dejando el offcanvas de 'Calculadora de Simulación' abierto y el botón 'Crear simulación' deshabilitado. Posteriormente, un comando cy.click() que intentaba interactuar con el botón 'Simular' principal (fuera del offcanvas) agotó su timeout después de 90050ms porque estaba cubierto por el offcanvas abierto.

Posibles causas

ALTA
Endpoint /investments/ devuelve 503 en producción.
El HAR muestra un POST https://api.mercapabbaco.com/investments/ con status 503 y response body 'Service Unavailable', lo que indica un problema en el backend de Mercap.
MEDIA
Regresión en la lógica de cierre/estado del offcanvas tras fallo de API.
Tras el 503 de la API, el offcanvas de simulación permaneció abierto y el botón 'Crear simulación' deshabilitado (visible en el screenshot), lo que llevó a que el botón 'Simular' principal quedara cubierto y no interactuable.
BAJA
Selector incorrecto o ambigüedad en el test.
El test intentó hacer clic en el botón 'Simular' del área principal mientras el offcanvas estaba abierto, lo que sugiere que el selector no apuntó al botón 'Crear simulación' dentro del offcanvas o que la secuencia de pasos es errónea para el estado actual de la UI. Sin embargo, la falla de la API es la causa más directa.
