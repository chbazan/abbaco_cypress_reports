Descripción detallada

El flujo de validación de cotizaciones de cierre falló al ejecutar un comando custom en 'commands.js:1006' que buscaba el botón 'Nuevo portafolio'. La captura de pantalla muestra que la aplicación ya se encuentra dentro de la vista de un portafolio específico ('Portafolio Cypress'), donde dicho botón no es visible. Adicionalmente, el HAR revela tres fallos 404 en el endpoint '/single-date-price' para el bono PECMO, lo que provoca que la UI muestre guiones ('-') en lugar de precios y un alert de advertencia sobre instrumentos sin precio actualizado.

Posibles causas

ALTA
Falta de datos en API Mercap (404)
El HAR muestra 3 requests fallidos a '/single-date-price' con el mensaje 'No hay precio para PECMO al 30 July 2026'. Esto rompe la precondición de datos del test y genera un estado de error en la UI.
ALTA
Lógica de navegación del test obsoleta
El test busca el botón 'Nuevo portafolio' (selector 'button' con texto regex), pero la UI ya está en '/security-position' visualizando un portafolio activo. El botón solo aparece en la vista de lista o cuando no hay portafolios creados.
MEDIA
Estado de la UI alterado por alert de error
La presencia del alert de 'precio no actualizado' debido al fallo de la API podría estar interfiriendo con el flujo esperado de la página o el orden de carga de los componentes.

Pasos de Troubleshooting

1 Verificar manualmente en producción si el bono PECMO tiene cotización de cierre cargada para el 2026-07-30.
2 Ejecutar el test localmente: TARGET_ENV=production TARGET_CLIENT=argentina SPEC=cotizaciones-cierre_02_check-closing-quotes-abbaco-arg npm run test
3 Inspeccionar 'cypress/support/commands.js' en la línea 1006 para flexibilizar la búsqueda del botón 'Nuevo portafolio' o manejar el caso de portafolio ya abierto.
4 Validar el estado de la API de Mercap mediante Postman usando el endpoint del HAR que devolvió 404 para confirmar si es un problema de ambiente.
5 Revisar si el test requiere una limpieza previa de portafolios (cleanup) para asegurar que el botón 'Nuevo portafolio' esté presente.
