Descripción detallada

El test falló al intentar validar la cotización de cierre del bono AL30 en el ambiente de producción. Según el screenshot, la aplicación lanzó un error de JavaScript crítico ('TypeError: t(...).internalRateOfReturnPercentageNumber is not a function') que interrumpió el flujo de renderizado. Esto provocó que Cypress agotara el timeout de 90000ms buscando un elemento input que nunca se generó en el DOM. El HAR registra 4 errores 500 en el endpoint /metrics de la API de Mercap, lo que sugiere una falla de datos subyacente.

ALTA
Error de JS en el frontend

ALTA
Inestabilidad en API Mercap
El HAR reporta múltiples errores 500 en https://api.mercapabbaco.com/tradable-securities/.../metrics, afectando la disponibilidad de datos para el bono.
BAJA
Timeout por carga lenta
Aunque hay un wait de 30s en el script, el error de JS es el bloqueante principal antes de que expire el timeout de Cypress.
