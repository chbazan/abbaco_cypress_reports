Descripción detallada

El test falló durante la validación de cotizaciones en el módulo de Calculadora. Según el error de Cypress, el input de 'Valor' se desprendió del DOM (detached) durante una operación de escritura, lo que indica un re-renderizado asincrónico de la UI. Sin embargo, la evidencia visual en el screenshot muestra un fallo previo de aserción: el valor en Abbaco (98200) no coincide con el esperado de Pepper (98480). El timeout de 90s sugiere que Cypress intentó reintentar la acción sobre un elemento que desapareció o cambió de estado debido a la actualización de datos.

Posibles causas

ALTA
Mismatch de cotización
El screenshot muestra explícitamente que 98200 != 98480. Esto dispara reintentos automáticos en Cypress que pueden derivar en errores de UI si la página se actualiza.
ALTA
Re-renderizado asincrónico (Detachment)
El mensaje de error técnico confirma que el input desapareció mientras cy.type() estaba en ejecución, típico de componentes React que se actualizan al recibir datos de la API.
MEDIA
Delay en actualización de API Mercap
Si la API de cotizaciones de cierre tarda en impactar el valor correcto, el test lee un valor desactualizado (98200) provocando el fallo de lógica.
