Mismatch de cotización en bono LECHO: Abbaco muestra 28000.0028 vs Pepper 28800

Descripción detallada

El test de validación de cotizaciones de cierre falló al comparar el valor extraído del DOM para el bono LECHO con el valor de referencia de Pepper. Según el log de Cypress y el screenshot, Abbaco reporta 28000.0028 (visualizado como 28.000,00 en la UI), mientras que la aserción esperaba 28800 +/- 0.1. La diferencia de 800 unidades indica una desincronización significativa entre las fuentes de datos.

Posibles causas

ALTA
Cotización desactualizada en Abbaco
El valor en la UI (28000) es menor al esperado (28800), lo que sugiere que Abbaco podría estar reflejando un precio de cierre anterior o que la ingesta de datos de ByMA para este bono específico está demorada.
MEDIA
Dato erróneo en la fuente Pepper
Si la fuente de referencia (Pepper) tiene un valor incorrecto o de una plaza distinta, la comparación fallará a pesar de que Abbaco muestre el dato oficial de ByMA.
BAJA
Error de parsing en el comando de extracción
Aunque el valor extraído es 28000.0028, la diferencia con 28800 es de magnitud y no parece ser un error de decimales o formato, dado que el screenshot confirma el valor de 28.000,00.

Pasos de Troubleshooting

1 Verificar manualmente la cotización de cierre de LECHO en Bolsar o ByMA para confirmar cuál es el valor real.
2 Ejecutar el test localmente: TARGET_ENV=production TARGET_CLIENT=argentina MODE=only SPEC=cotizaciones-cierre_02_check-closing-quotes-abbaco-arg npm run test
3 Consultar el endpoint de la API de Mercap para el bono LECHO y comparar el campo de precio de cierre con el valor de Pepper.
4 Revisar los logs de sincronización de precios en el backend para detectar fallos en la actualización de bonos específicos.
