Error 401 Unauthorized en API Mercap al obtener cotización de AL30 — Fallo de autenticación Basic Auth.

Descripción detallada

El test ejecuta el flujo de obtención de cotizaciones vía API en el spec '01_check-closing-quotes-pepper'. Falla inmediatamente (942ms) al realizar un cy.request() al endpoint de tradable-securities. La respuesta del servidor es un 401 Unauthorized, indicando que las credenciales Basic Auth enviadas en el header no son válidas para el ambiente de producción.

Posibles causas

ALTA
Credenciales Basic Auth inválidas
El log de Cypress muestra el header 'authorization: Basic c21va2U6RzUydFYlS2RJN0Aj' siendo rechazado con status 401 por api.mercapabbaco.com.
MEDIA
Cambio en políticas de seguridad de la API
El endpoint podría haber migrado a un esquema de autenticación diferente o restringido el acceso al usuario smoke en producción.

Pasos de Troubleshooting

1 Verificar validez de las credenciales Basic Auth manualmente usando curl o Postman contra el endpoint afectado.
2 Revisar los secretos y variables de entorno en el CI/CD para el ambiente production/argentina.
3 Reproducir localmente: TARGET_ENV=production TARGET_CLIENT=argentina SPEC=01_check-closing-quotes-pepper.cy.js npm run test
4 Consultar con el equipo de Backend/DevOps si hubo rotación de llaves para la API de Mercap.

Descripción detallada

Posibles causas

ALTA
Dependencia de test previo no satisfecha
El Spec 02 depende de los datos guardados por el Spec 01. Al fallar el primero, el segundo no encuentra el archivo necesario para la comparación.
BAJA
Timeout de carga de página

3 Ejecutar la suite completa localmente para asegurar que el flujo de datos entre specs sea consistente.
