Fallo por sesión evictada (modal 'Ingresaste desde otro dispositivo') durante validación de cotización LECHO

Descripción detallada

El test ejecutaba la validación de cotización de cierre para el bono LECHO en producción. Al intentar interactuar con un elemento de entrada, Cypress falló tras 90s porque el elemento estaba cubierto por un modal de clase 'session-evicted-modal'. La captura de pantalla confirma el mensaje 'Ingresaste a tu cuenta desde otro dispositivo', y el HAR muestra un error 401 en el endpoint de anuncios, lo que indica una pérdida de autorización en medio del flujo.

Posibles causas

ALTA
Concurrencia de cuenta de QA
El modal 'session-evicted-modal' es característico de Abbaco cuando la misma cuenta se utiliza en dos sesiones simultáneas. Es probable que otro job de CI o un desarrollador haya usado las mismas credenciales.
MEDIA
Token de sesión expirado o inválido
El HAR registra un GET a /abbaco-announcements/records con status 401. Si la lógica de la app dispara el desalojo de sesión ante cualquier 401 de la API de Mercap, esto explicaría la aparición del modal.

Pasos de Troubleshooting

1 Verificar en el panel de CI si hay ejecuciones paralelas utilizando el mismo usuario de Argentina.
2 Reproducir localmente limpiando el estado de cy.session: TARGET_ENV=production TARGET_CLIENT=argentina SPEC=cotizaciones-cierre_02_check-closing-quotes-abbaco-arg npm run test
3 Verificar en el dashboard de Auth0 los logs de login para el usuario afectado.
4 Validar si el endpoint /abbaco-announcements/records requiere una sesión fresca que cy.SessionAbbaco() no esté proveyendo correctamente.
