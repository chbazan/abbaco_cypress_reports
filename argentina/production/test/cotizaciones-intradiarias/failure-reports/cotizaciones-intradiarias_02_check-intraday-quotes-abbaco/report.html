Mismatch de cotización en LECHO: Abbaco muestra 27600.0027 vs 30200 esperado de Pepper

Descripción detallada

El test falló al validar la cotización intradiaria del bono LECHO en el módulo Analizar. Se obtuvo el valor '27600.0027' del DOM mediante el selector 'span.me-2', pero la aserción falló al compararlo contra el valor de referencia '30200' (Pepper). La captura de pantalla confirma que la UI muestra efectivamente '27.600,00 ARS', descartando un error de captura del selector y confirmando una discrepancia de datos.

Posibles causas

ALTA
Dato desactualizado en API Mercap
El HAR muestra que la request a /metrics y /quotes/LECHO devolvieron 200/304 exitosamente, lo que indica que la UI está mostrando lo que la API provee, pero dicho valor no coincide con la realidad del mercado (Pepper).
MEDIA
Delay en la ingesta de precios intradiarios
Existe una brecha temporal entre la actualización del precio en BYMA/Pepper y su reflejo en la plataforma Abbaco para este ticker específico.

Pasos de Troubleshooting

1 Verificar manualmente la cotización de LECHO en la terminal de BYMA o fuente oficial externa.
2 Ejecutar el test localmente: TARGET_ENV=production TARGET_CLIENT=argentina MODE=only SPEC=cotizaciones-intradiarias_02_check-intraday-quotes-abbaco.cy.js npm run test
3 Inspeccionar la respuesta del endpoint https://api.mercapabbaco.com/tradable-securities/2a069e90-6234-44fd-bda9-93067b480ea8/metrics para validar el campo lastPrice.
4 Revisar logs de integración entre Pepper y Mercap para detectar posibles fallos en el pipeline de datos.
