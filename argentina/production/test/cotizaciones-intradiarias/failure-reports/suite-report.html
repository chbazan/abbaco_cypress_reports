Descripción detallada

El test falló al validar la cotización intradiaria del bono AL30 en el módulo Analizar. Se observó que el valor capturado de la UI de Abbaco (92430.0092) difiere significativamente del valor de referencia esperado de Pepper (92500). La captura de pantalla confirma que la UI muestra '92.430,00', lo que indica que el dato fue extraído correctamente pero existe una desincronización con la fuente de comparación.

Posibles causas

ALTA
Delay en la actualización de precios de la API de Mercap
La UI muestra un valor de 92430.00 mientras que el test espera 92500. Esta diferencia de ~70 unidades suele deberse a latencia en la ingesta del feed de ByMA por parte de Mercap en comparación con la fuente Pepper.
MEDIA
Mismatch entre Precio Sucio y Precio Limpio
Si Pepper reporta un tipo de precio y Abbaco otro (o aplica un coeficiente distinto), se producen estas discrepancias numéricas constantes.
BAJA
Volatilidad extrema del mercado
Un salto de precio brusco entre el momento en que el test consulta Pepper y el momento en que lee la UI de Abbaco.

1 Reproducir el fallo localmente: TARGET_ENV=production TARGET_CLIENT=argentina MODE=only SPEC=cotizaciones-intradiarias_02_check-intraday-quotes-abbaco.cy.js npm run test

4 Validar en el código del test la lógica de obtención del valor de 'Pepper' para asegurar que no haya un error de redondeo o de instrumento.
5 Revisar logs de infraestructura para detectar demoras en el procesamiento de colas de precios (RabbitMQ/Kafka) de la plataforma.
