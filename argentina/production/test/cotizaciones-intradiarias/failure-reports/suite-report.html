Mismatch de cotización intradiaria en AL30: Abbaco (90440.009) vs Pepper (90530) — diferencia de ~90 ARS

Descripción detallada

El test 'Validar en Abbaco que la cotización intradiaria del bono AL30 sea la correcta' falló al comparar el valor extraído de la UI contra la referencia de Pepper. Cypress obtuvo '90440.009' del elemento 'span.me-2' en el módulo Analizar, pero la API de referencia reportó '90530'. La captura de pantalla confirma que la UI muestra '90.440,00', lo que descarta un error de parsing y confirma una discrepancia de datos pura.

Posibles causas

ALTA
Latencia en la actualización de precios de Mercap
La UI de Abbaco refleja un precio rezagado (90440.009) respecto a la referencia (90530). Es el patrón de fallo típico de desincronización de proveedores de mercado.
MEDIA
Diferencia en la punta de precio seleccionada
Abbaco podría estar tomando el 'último operado' mientras que la referencia de Pepper podría estar usando 'bid/ask' o un promedio ponderado, generando el gap de 90 ARS.
BAJA
Cache agresivo en el endpoint de cotizaciones
Si el endpoint de Mercap tiene un TTL de cache elevado, la UI mostrará valores viejos mientras el test consulta una referencia viva.

Pasos de Troubleshooting

1 Verificar manualmente la cotización de AL30 en una terminal de ByMA o Matba Rofex para identificar cuál proveedor es el correcto.
2 Reproducir localmente con: TARGET_ENV=production TARGET_CLIENT=argentina SPEC=cotizaciones-intradiarias_02_check-intraday-quotes-abbaco.cy.js npm run test
3 Inspeccionar el response de la API de Mercap en el HAR para ver el timestamp exacto del precio '90440.009'.
4 Comparar los logs de integración de precios en Datadog para detectar picos de latencia entre las 13:00 y 13:10 UTC.
5 Validar si el error persiste para otros bonos de alta liquidez (GD30, AL29) para descartar un problema sistémico de la API.
