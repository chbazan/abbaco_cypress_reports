Descripción detallada

El test falló al validar que la cotización de AL30 en la UI coincidiera con el valor de referencia de Pepper. La aserción falló con 'expected 93650.0093 to be close to 93640 +/- 0.1', indicando una discrepancia de ~10 ARS. El screenshot confirma que la UI de Abbaco muestra '93.650,00', lo que descarta problemas de carga de elementos o placeholders.

Posibles causas

ALTA
Desincronización de datos de mercado
La diferencia significativa de valor sugiere que la API de Mercap no está reflejando el último precio operado capturado por Pepper, posiblemente por delay en la ingesta de feeds de ByMA.
MEDIA
Delay en actualización de la UI
El test pudo haber capturado el valor antes de que el componente de cotización recibiera la última actualización vía polling o socket.
