El comando personalizado 'validarCard' extrajo el texto '91.150,00' de la UI, pero el valor esperado era '91250'. La duración de 11s y el HAR con 0 fallos confirman que la página cargó correctamente, pero los datos no coinciden.

Posibles causas

ALTA
Volatilidad de mercado
El precio del bono AL30 cambió entre el momento en que el test obtuvo el valor esperado y el momento de la validación en la UI.
MEDIA
Fixture o valor de referencia desactualizado
El test podría estar comparando contra un valor estático o una respuesta de API de referencia que no está sincronizada con la UI de Abbaco en tiempo real.
BAJA
Desincronización de caché de cotizaciones
La UI muestra un valor 'atrasado' respecto a la fuente de datos que el test usa para definir el 'expected'.
