Descripción detallada

El test falló durante la validación de la cotización intradiaria del bono AL30 en el módulo Analizar. La aserción falló al comparar el valor capturado de la UI (93450.0093) contra el valor de referencia esperado de Pepper (93200), resultando en una diferencia de ~250 unidades. El HAR registra una respuesta lenta (8022ms) en el endpoint de métricas del activo, lo que sugiere latencia en la sincronización de datos de mercado al momento de la ejecución.

Posibles causas

ALTA
Desincronización de datos de mercado
La API de Mercap devolvió un valor (93450.0093) que no coincide con el valor de referencia de Pepper (93200). Esto suele ocurrir por delays en el pipeline de procesamiento de cotizaciones intradiarias.
MEDIA
Latencia excesiva en API de métricas
El request GET a /metrics tardó 8022ms. Esta demora puede causar que el test capture un valor 'stale' (viejo) antes de que la UI se actualice con el último precio disponible.
BAJA
Error de cálculo o redondeo en el backend
El valor 93450.0093 presenta una precisión de 4 decimales que podría no estar alineada con las reglas de negocio de BYMA para este instrumento.
