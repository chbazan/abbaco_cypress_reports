Cotizaciones-intradiarias: Mismatch de precio en BDC28 (Abbaco 107.101 vs Pepper 110.0)

Descripción detallada

El test valida que la cotización intradiaria del bono BDC28 en la UI coincida con el valor de referencia de Pepper. El flujo falló en la aserción final tras extraer exitosamente el valor '107.101' del DOM (confirmado en screenshot y logs de Cypress). La captura de pantalla muestra '107,10' en el campo 'Últ. Cotización', mientras que el test esperaba un valor cercano a '110' con una tolerancia de +/- 0.1. No se detectaron errores de red en el HAR (0 fallidos), lo que confirma que la UI cargó los datos que la API proveyó, pero estos no coinciden con la expectativa del test.

Posibles causas

ALTA
Delay en la ingesta de datos de Mercap
La API de Mercap puede estar reportando un precio atrasado o de un cierre anterior, mientras que la referencia Pepper ya actualizó a 110.0. El HAR no muestra errores de red, indicando que el dato llegó pero es divergente.
MEDIA
Diferencia de plazos de liquidación
Abbaco podría estar mostrando el precio en Contado Inmediato (CI) mientras que la referencia Pepper usa 48hs, o viceversa, generando la brecha de ~2.7% observada.
BAJA
Error en la fuente de referencia Pepper
El valor '110' esperado por el test podría ser un dato erróneo inyectado como fixture o consultado de una API externa que no refleja la realidad de ByMA en ese instante.

Pasos de Troubleshooting

1 Verificar manualmente la cotización de BDC28 en ByMA/MAE para confirmar cuál de los dos valores (107.10 o 110.0) es el correcto en tiempo real.
2 Ejecutar el test localmente: TARGET_ENV=production TARGET_CLIENT=argentina SPEC=cotizaciones-intradiarias_02_check-intraday-quotes-abbaco.cy.js npm run test
3 Revisar en el HAR la respuesta del endpoint de la API de Mercap para BDC28 y verificar el campo 'datetime' del precio para descartar datos 'stale'.
4 Validar si el bono BDC28 tuvo operaciones recientes; la falta de liquidez puede causar que el precio no se actualice en Abbaco mientras Pepper proyecta valores teóricos.
