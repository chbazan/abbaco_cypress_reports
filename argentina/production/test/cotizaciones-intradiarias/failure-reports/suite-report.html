Descripción detallada

El test 'Validar la cotización intradiaria del bono PECMO en la sección Bonos Favoritos' intentaba verificar la presencia de la tarjeta de cotización del bono PECMO. El fallo ocurrió al intentar encontrar el elemento `.tradable-security-preview-card` en la sección 'Bonos favoritos', agotando el timeout de 15 segundos para el comando `cy.get`. La evidencia del DOM al momento del fallo muestra que la sección 'Bonos favoritos' contenía placeholders vacíos (ej. '9/15', '10/15') en lugar de las tarjetas de bonos esperadas, mientras que el DOM de un test exitoso sí las muestra. Se observa una request lenta a `historical-data.mercapabbaco.com/irrs?short-names=AL41` (4436ms), lo que sugiere problemas de rendimiento en la API de datos históricos.

Posibles causas

ALTA
API de Mercap lenta o sin respuesta para datos de bonos.
El HAR muestra una request lenta a `historical-data.mercapabbaco.com/irrs` (4436ms). Aunque es para AL41, indica un posible problema general de rendimiento de la API de datos históricos, lo que podría haber afectado la carga de PECMO. El DOM-FALLO muestra la ausencia de las tarjetas de bonos, lo que es consistente con una falta de datos.
MEDIA
Fallo en el renderizado del componente `TradableSecurityPreviewCard`.
Aunque los datos lleguen, un bug en el componente podría impedir que se renderice correctamente o que el selector `.tradable-security-preview-card` sea aplicado. El DOM-FALLO muestra placeholders genéricos en su lugar, lo que podría indicar un problema en la lógica de renderizado tras recibir los datos.
BAJA
El bono PECMO no está configurado como favorito para el usuario de prueba.
Si el bono no está en la lista de favoritos del usuario, la tarjeta nunca se intentaría renderizar. Sin embargo, el test está diseñado para validar un bono específico, lo que implica que debería estar configurado. Es una posibilidad remota si la configuración de datos de prueba es incorrecta.

Pasos de Troubleshooting

1 Reproducir el spec localmente: `TARGET_ENV=production TARGET_CLIENT=argentina MODE=only SPEC=cotizaciones-intradiarias_02_check-intraday-quotes-abbaco npm run test`
2 Abrir la aplicación manualmente en `https://bonds.mercapabbaco.com/` y navegar a 'Bonos Favoritos' para verificar si las cotizaciones de bonos (especialmente PECMO) cargan correctamente y a qué velocidad.
3 Monitorear los logs de la API de Mercap en Datadog para `historical-data.mercapabbaco.com/irrs` en el ambiente de producción, buscando errores o latencias elevadas que puedan afectar la carga de datos de bonos.
4 Verificar si el bono PECMO está correctamente configurado como favorito para el usuario de prueba en el ambiente de producción.
5 Inspeccionar el código del componente `TradableSecurityPreviewCard` y su lógica de carga de datos para identificar posibles race conditions o errores de estado que impidan su renderizado.
