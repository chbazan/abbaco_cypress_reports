Descripción detallada

El test estaba validando la cotización intradiaria del bono AL30 en la pestaña 'Simular Inversión' dentro del módulo 'Analizar'. El fallo ocurrió cuando Cypress intentó hacer clic en la pestaña 'Simular Inversión', pero la acción fue bloqueada. El comando `cy.click()` agotó su timeout después de 90050ms porque un modal (`div[role="dialog"]`) con el título 'Conoce los planes de Abbaco' estaba cubriendo el elemento objetivo. Adicionalmente, se observaron múltiples errores 401 'No authorization provided' en requests a `/abbaco-announcements/records` en el HAR, lo que podría indicar un problema de sesión concurrente.

Posibles causas

ALTA
Modal inesperado bloqueando UI
El screenshot y el mensaje de error de Cypress confirman que un modal (`div[role="dialog"]`) está cubriendo el botón de la pestaña 'Simular Inversión', impidiendo el click.
MEDIA
Fallo de sesión Auth0 o API de anuncios
Múltiples requests a `/abbaco-announcements/records` devuelven 401 'No authorization provided' en el HAR, lo que podría indicar una sesión inválida o expirada, y potencialmente influir en la aparición de UI inesperada o ser un problema concurrente.
MEDIA
Cambio de UI/UX no contemplado
Una actualización reciente en la interfaz de usuario podría haber introducido este modal en el flujo de 'Analizar' sin que el test haya sido adaptado para manejarlo.

Pasos de Troubleshooting

1 Reproducir el spec fallido localmente con TARGET_ENV=production TARGET_CLIENT=argentina MODE=only SPEC=cotizaciones-intradiarias_02_check-intraday-quotes-abbaco npm run test para observar el comportamiento del modal.
2 Verificar manualmente en `production/argentina` si el modal 'Conoce los planes de Abbaco' aparece al navegar a la sección 'Analizar' y al bono AL30.
3 Revisar la implementación de `cy.SessionAbbaco()` y las credenciales para `production/argentina` debido a los errores 401 en el HAR.
4 Si el modal es esperado, agregar un paso para cerrarlo (`cy.get('.modal-close-button').click()`) antes de interactuar con la pestaña 'Simular Inversión'.
