Mismatch de cotización intradiaria en LECHO: Abbaco (28800.0028) vs Pepper (28000)

Descripción detallada

El test falló durante la validación de precios en tiempo real para el bono LECHO en el módulo Analizar. El script comparó el valor extraído de la plataforma Abbaco (28800.0028) contra el valor de referencia de la fuente Pepper (28000), encontrando una discrepancia significativa. La captura de pantalla confirma que la UI muestra '28.800,00', validando que el dato en Abbaco es consistente con su UI pero difiere de la fuente externa de comparación.

Posibles causas

ALTA
Desincronización de cotización intradiaria
El valor en Abbaco es 28800.0028 mientras que Pepper reporta 28000. Esto indica un delay en la actualización de una de las dos fuentes o un error en la ingesta de BYMA.
MEDIA
Diferencia de precisión decimal en la comparación
El error reporta '28800.0028' (4 decimales), mientras que la UI muestra '28.800,00'. El test podría estar comparando valores crudos de API sin el redondeo de negocio aplicado por Pepper.
BAJA
Cache de cotización en el ambiente de producción
La API de Mercap podría estar sirviendo un valor cacheado antiguo para el bono LECHO mientras Pepper ya actualizó a un nuevo precio de mercado.

1 Verificar manualmente la cotización actual de LECHO en BYMA o terminal de mercado para confirmar cuál fuente es correcta.
2 Ejecutar el test localmente: TARGET_ENV=production TARGET_CLIENT=argentina MODE=only SPEC=cotizaciones-intradiarias_02_check-intraday-quotes-abbaco npm run test

5 Verificar si el bono LECHO tuvo operaciones recientes con precios dispersos que justifiquen la diferencia.
